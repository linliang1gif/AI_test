# 前端启动说明

## ⚠️ 重要提示

这个项目使用的是 **Vite** 而不是 Create React App，所以启动命令不同！

## 正确的启动命令

### ✅ 正确
```bash
cd ai-test-platform/frontend
npm run dev
```

### ❌ 错误
```bash
npm start  # 这个命令不存在！
```

## 访问地址

启动后，前端运行在:
- **Vite 默认端口**: http://localhost:5173
- **不是** http://localhost:3000

## 完整启动流程

### 1. 启动后端
```bash
# 终端1
cd ai-test-platform
python backend_api_server.py
```

验证: http://localhost:5000/health

### 2. 启动前端
```bash
# 终端2
cd ai-test-platform/frontend
npm run dev
```

看到类似输出:
```
  VITE v4.5.0  ready in 1234 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h to show help
```

### 3. 访问前端
打开浏览器: http://localhost:5173

## 常见问题

### Q1: 提示 "Missing script: start"
**A**: 使用 `npm run dev` 而不是 `npm start`

### Q2: 端口被占用
**A**: Vite 会自动使用下一个可用端口 (5174, 5175...)

### Q3: 页面空白
**A**: 
1. 检查浏览器控制台错误
2. 确认后端已启动
3. 清除浏览器缓存

### Q4: 修改代码不生效
**A**: Vite 支持热重载，保存文件后会自动刷新。如果不生效:
```bash
# Ctrl+C 停止
npm run dev  # 重新启动
```

## 可用的 npm 命令

```bash
npm run dev      # 启动开发服务器
npm run build    # 构建生产版本
npm run preview  # 预览生产构建
npm run lint     # 运行 ESLint
```

## 开发服务器配置

如果需要修改端口或其他配置，编辑 `vite.config.js`:

```javascript
export default defineConfig({
  server: {
    port: 3000,  // 修改端口
    host: true,  // 暴露到网络
  }
})
```

**记住: 使用 `npm run dev` 启动前端！**
