## ❌ 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| 连接拒绝 | 后端未启动 | 启动 backend_api_server.py |
| Token错误 | Token过期/未配置 | 重新获取Token |
| 端口占用 | 8000/5173被占用 | 结束占用进程 |
| npm start失败 | 错误命令 | 使用 `npm run dev` |
