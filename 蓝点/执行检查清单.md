## ❌ 常见问题排查

### 问题1: Token错误

**症状**: 
```
✗ 鉴权配置创建失败
状态码: 401
```

**解决**:
- [ ] 检查Token是否过期
- [ ] 重新登录蓝点系统获取新Token
- [ ] 更新 `.env.bluedot` 文件
- [ ] 重新执行脚本

### 问题2: 连接拒绝

**症状**:
```
✗ 请求失败: ConnectionError
```

**解决**:
- [ ] 检查后端是否启动 (http://localhost:8000/health)
- [ ] 检查端口是否被占用
- [ ] 重启后端服务

### 问题3: 文件不存在

**症状**:
```
✗ OpenAPI文件不存在
```

**解决**:
- [ ] 检查文件路径: `蓝点/bluedot_openapi.json`
- [ ] 确认文件存在且可读
- [ ] 检查文件大小 (应该 > 1MB)

### 问题4: 端口占用

**症状**:
```
Address already in use
```

**解决**:
```bash
# 检查端口占用
netstat -ano | findstr :8000
netstat -ano | findstr :5173

# 结束进程
taskkill /PID <进程ID> /F
```

### 问题5: npm start 失败

**症状**:
```
Missing script: "start"
```

**解决**:
- [ ] 使用正确命令: `npm run dev` (不是 npm start)
- [ ] 确认在 frontend 目录下执行
