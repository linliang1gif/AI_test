## ⚠️ 常见问题预检

### 问题 1: Token 未设置
**现象**: 脚本提示 "请先设置BLUEDOT_TOKEN"

**解决**:
1. 确认已登录蓝点系统
2. 重新获取 Token
3. 更新脚本中的 BLUEDOT_TOKEN
4. 确保 Token 不是默认值

### 问题 2: 后端未启动
**现象**: 脚本提示连接失败

**解决**:
```bash
# 检查后端进程
ps aux | grep backend_api_server

# 如果未运行，启动后端
cd ai测试/ai-test-platform
python backend_api_server.py
```

### 问题 3: 数据库未初始化
**现象**: 后端启动时提示缺少表

**解决**:
```bash
cd ai测试/ai-test-platform
python init_db.py
```

### 问题 4: OpenAPI 文件不存在
**现象**: 步骤4失败，提示文件不存在

**解决**:
```bash
# 检查文件
ls -lh 蓝点/bluedot_openapi.json

# 如果不存在，检查路径
pwd
# 应该在 ai测试 目录下
```

### 问题 5: 网络连接失败
**现象**: 步骤6或7失败，请求蓝点 API 超时

**解决**:
1. 确认 VPN 已连接
2. 测试网络: `ping dev-recycle.szhibu.com`
3. 在浏览器中访问蓝点系统确认可访问
4. 重新获取 Token（可能已过期）
