## 使用指南

### 查看蓝点项目

1. **启动前端**
   ```bash
   cd ai-test-platform/frontend
   npm run dev
   ```

2. **访问项目列表**
   - 打开浏览器: http://localhost:3000
   - 自动跳转到项目列表页
   - 在列表中找到"蓝点回收系统"

3. **查看项目详情**
   - 点击"蓝点回收系统"
   - 查看项目信息、环境配置、API规范

4. **查看测试用例**
   - 点击侧边栏"测试用例"
   - 筛选来源为"swagger"
   - 查看币别管理相关用例

5. **查看执行记录**
   - 点击侧边栏"执行记录(V2)"
   - 找到蓝点项目的TestRun
   - 点击查看详情

6. **查看执行详情**
   - 在TestRun详情页
   - 查看RunCase列表
   - 点击查看单个RunCase的快照和断言结果

## 页面功能说明

### 项目列表页 (ProjectsV2)
- 显示所有项目
- 支持搜索和筛选
- 显示项目统计信息
- 可创建新项目

### 项目详情页 (ProjectDetailV2)
- 项目基本信息
- 环境配置列表
- 鉴权配置列表
- API规范列表
- 测试用例统计
- 执行记录统计

### 测试用例页 (TestCases)
- 显示所有测试用例
- 支持按项目、来源、状态筛选
- 显示用例详情
- 可编辑和执行用例

### 执行记录页 (TestRunsV2)
- 显示所有TestRun
- 支持按项目、状态筛选
- 显示执行统计
- 可查看详情

### 执行详情页 (TestRunDetailV2)
- TestRun基本信息
- RunCase列表
- RunStep列表
- 状态历史
- 请求/响应快照
- 断言结果

## 注意事项

### 1. 前端需要重启
修改 App.jsx 后，前端会自动热重载。如果没有，请手动重启:
```bash
# Ctrl+C 停止
npm run dev
```

### 2. 后端必须运行
前端页面需要调用后端API，确保后端已启动:
```bash
cd ai-test-platform
python backend_api_server.py
```

### 3. 数据库必须初始化
确保数据库已初始化:
```bash
cd ai-test-platform
python init_db.py
```

### 4. 浏览器缓存
如果页面显示异常，清除浏览器缓存:
- Chrome: Ctrl+Shift+Delete
- 或使用无痕模式: Ctrl+Shift+N
