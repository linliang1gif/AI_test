# 端口说明

## ⚠️ 重要：端口配置

### 实际端口
- **后端**: http://localhost:8000 (不是 5000!)
- **前端**: http://localhost:5173 (不是 3000!)

### 为什么不同？
1. **后端**: backend_api_server.py 默认配置是 8000 端口
2. **前端**: Vite 默认使用 5173 端口

### 已修正的文件
- ✅ `bluedot_platform_integration.py` - 已改为 8000
- ✅ `verify_bluedot_integration.py` - 已改为 8000 和 5173

## 如果需要修改端口

### 修改后端端口
编辑 `ai-test-platform/backend_api_server.py` 最后一行:
```python
uvicorn.run(app, host="0.0.0.0", port=8000)  # 修改这里的端口
```

### 修改前端端口
编辑 `ai-test-platform/frontend/vite.config.js`:
```javascript
export default defineConfig({
  server: {
    port: 5173  // 修改这里的端口
  }
})
```

---

**记住: 后端 8000，前端 5173！**
