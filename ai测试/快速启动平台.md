# 快速启动平台

## ⚡ 两步启动

### 第一步：启动后端
```bash
cd ai-test-platform
python backend_api_server.py
```

看到类似输出表示成功:
```
✅ 已加载环境变量
✅ Modules SDK 已加载
✅ Core Models 已加载
...
INFO:     Uvicorn running on http://0.0.0.0:5000
```

验证: http://localhost:5000/health

### 第二步：启动前端
```bash
# 新开一个终端
cd ai-test-platform/frontend
npm run dev
```

看到类似输出表示成功:
```
  VITE v4.5.0  ready in 1234 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

访问: http://localhost:5173

## ⚠️ 重要提示

### 前端启动命令
- ✅ **正确**: `npm run dev` (Vite项目)
- ❌ **错误**: `npm start` (会报错 "Missing script")

### 访问地址
- 后端: http://localhost:5000
- 前端: http://localhost:5173 (不是3000!)

## 🔍 验证清单

- [ ] 后端启动成功，访问 /health 返回 200
- [ ] 前端启动成功，页面正常加载
- [ ] 可以看到项目列表页
- [ ] 侧边栏菜单正常显示

## 🚀 执行蓝点项目接入

平台启动后，执行接入脚本:

```bash
# 新开第三个终端
cd ai测试
python bluedot_platform_integration.py
```

## 📝 常见问题

### Q: 前端提示 "Missing script: start"
**A**: 使用 `npm run dev` 而不是 `npm start`

### Q: 后端提示数据库错误
**A**: 先初始化数据库
```bash
cd ai-test-platform
python init_db.py
```

### Q: 前端页面空白
**A**: 
1. 检查后端是否启动
2. 打开浏览器控制台查看错误
3. 清除浏览器缓存
