# 一键启动说明

## 🚀 快速启动（三个批处理文件）

我已经为你创建了三个批处理文件，简化启动流程：

### 1. 启动后端.bat
**功能**: 
- 自动检查数据库是否存在
- 如果不存在，自动初始化
- 启动后端服务器

**使用**:
```
双击 "启动后端.bat"
```

**验证**:
- 看到 "Uvicorn running on http://0.0.0.0:5000"
- 访问 http://localhost:5000/health 返回 200

### 2. 启动前端.bat
**功能**:
- 启动前端开发服务器 (Vite)

**使用**:
```
双击 "启动前端.bat"
```

**验证**:
- 看到 "Local: http://localhost:5173/"
- 访问 http://localhost:5173 页面正常加载

### 3. 执行蓝点接入.bat
**功能**:
- 自动检查后端是否运行
- 如果后端未运行，提示先启动
- 执行蓝点项目平台接入脚本

**使用**:
```
双击 "执行蓝点接入.bat"
```

**前提**:
- 后端必须已启动
- Token 已更新到 bluedot_platform_integration.py

## ⚠️ 常见问题

### Q1: 双击批处理文件闪退
**A**: 这是正常的，说明脚本执行完成了。如果想看输出，在命令行中运行。

### Q2: 后端启动失败
**A**: 
1. 检查 Python 是否安装
2. 检查依赖是否安装: `pip install -r requirements.txt`
3. 查看错误信息

### Q3: 前端启动失败
**A**:
1. 检查 Node.js 是否安装
2. 检查依赖是否安装: `npm install`
3. 查看错误信息

### Q4: 执行接入失败
**A**:
1. 确认后端已启动
2. 确认 Token 已更新
3. 查看错误信息

## 🔍 手动启动（如果批处理文件不工作）

### 启动后端
```bash
cd ai-test-platform
python backend_api_server.py
```

### 启动前端
```bash
cd ai-test-platform/frontend
npm run dev
```

### 执行接入
```bash
cd ai测试
python bluedot_platform_integration.py
```
