# 测试用例功能使用说明

## 功能概述

测试用例管理功能支持:
1. 📤 上传需求文档自动生成测试用例
2. 📋 显示完整的测试用例信息(标题、模块、步骤、预期结果等)
3. 📥 导出测试用例为Excel格式
4. 🔍 查看测试用例详细信息

## 使用步骤

### 1. 启动服务

确保前后端服务都在运行:
- 后端: http://127.0.0.1:8081
- 前端: http://localhost:3000

### 2. 上传需求文档生成测试用例

1. 访问前端页面: http://localhost:3000
2. 点击左侧菜单 "测试用例"
3. 点击右上角 "导入需求文档" 按钮
4. 选择需求文档文件(支持 .txt, .md, .docx, .pdf, .xlsx)
5. 点击 "开始生成" 按钮
6. 等待AI生成完成

**支持的文档格式:**
- .txt - 纯文本文件
- .md - Markdown文件
- .docx - Word文档
- .pdf - PDF文档
- .xlsx - Excel表格

### 3. 查看测试用例

生成完成后,测试用例会显示在列表中,包含:
- 用例名称: 完整的测试用例标题(不是占位符)
- 模块: 功能模块名称
- 优先级: 高/中/低
- 来源: AI生成/人工/知识库
- 状态: 通过/失败/待运行
- 最后运行: 运行时间

### 4. 查看测试用例详情

1. 在测试用例列表中找到目标用例
2. 点击 "查看详情" 按钮
3. 弹出对话框显示完整信息:
   - 用例标题
   - 所属模块
   - 优先级
   - 测试步骤(详细步骤列表)
   - 预期结果
   - 状态
   - 最后运行时间

### 5. 导出Excel

1. 点击右上角 "导出Excel" 按钮
2. 浏览器会自动下载Excel文件
3. 文件名格式: `测试用例_YYYYMMDD_HHMMSS.xlsx`

**Excel包含的字段:**
- ID
- 标题
- 测试步骤
- 预期结果
- 优先级
- 模块
- 状态
- 最后执行

## 测试用例生成逻辑

后端AI会根据需求文档内容:
1. 解析文档内容
2. 识别功能模块(登录、订单、支付等)
3. 提取关键需求点
4. 生成测试步骤
5. 生成预期结果
6. 设置优先级

**示例需求文档:**
```
用户登录功能需求
1. 用户可以使用用户名和密码登录系统
2. 登录成功后跳转到首页
3. 登录失败显示错误提示
4. 支持记住密码功能
5. 支持找回密码功能
```

**生成的测试用例:**
- 标题: "AI生成 - 用户登录功能测试"
- 模块: "用户认证"
- 步骤: ["打开登录页面", "输入用户名和密码", "点击登录按钮", "验证登录结果"]
- 预期: "用户成功登录系统"
- 优先级: "High"

## API接口

### 生成测试用例
```
POST http://127.0.0.1:8081/api/testcases/generate
Content-Type: multipart/form-data

file: <需求文档文件>
```

### 获取测试用例列表
```
GET http://127.0.0.1:8081/api/test-cases
```

### 导出Excel
```
GET http://127.0.0.1:8081/api/test-cases/export
```

## 验证测试

运行测试脚本验证功能:
```bash
py test_testcase_display_export.py
```

测试内容:
1. 上传需求文档生成测试用例
2. 验证测试用例标题不是占位符
3. 验证Excel导出功能

## 注意事项

1. 需求文档应该包含清晰的功能描述
2. 文档编码建议使用UTF-8
3. Excel导出文件保存在 `output/` 目录
4. 测试用例ID自动递增
5. 前端会自动热更新,修改代码后无需重启
