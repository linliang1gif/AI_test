# 测试数据使用流程说明

## 📊 当前状态

### ✅ 已完成 (P1.4 集成1)
**API Explorer + 测试数据工厂**

点击"使用此数据"后,数据会:
1. 保存在ApiExplorer组件的state中
2. 显示提示:"测试数据已生成!可以在API测试中使用"
3. 数据存储在: `testData[api.id] = {...生成的数据}`

**当前限制**:
- ❌ 数据只在当前页面有效
- ❌ 刷新页面后数据丢失
- ❌ 其他模块无法访问这些数据
- ❌ 没有API测试执行功能

---

## 🎯 完整的数据流向 (规划中)

### 阶段1: API Explorer (✅ 已完成)
```
用户操作流程:
1. 导入Swagger → 显示API列表
2. 点击"🏭 测试数据" → 打开生成器
3. 点击"🎲 生成数据" → 调用后端生成
4. 点击"✅ 使用此数据" → 保存到state
5. 显示提示消息
```

**数据位置**: 
- 前端: `ApiExplorer.testData[apiId]`
- 后端: 无持久化

---

### 阶段2: API测试执行 (⏳ 待开发)
**功能**: 在API Explorer中直接测试API

```
增强后的流程:
1. 生成测试数据
2. 点击"使用此数据"
3. 数据自动填充到请求体输入框
4. 点击"▶️ 执行"按钮
5. 发送HTTP请求到目标API
6. 显示响应结果
```

**需要添加**:
- API执行面板
- 请求参数输入框
- 响应结果显示
- 历史记录保存

---

### 阶段3: 数据集管理 (⏳ P1.4 集成3)
**功能**: 保存和管理测试数据集

```
数据集流程:
1. 生成测试数据
2. 点击"💾 保存为数据集"
3. 输入数据集名称
4. 保存到后端数据库
5. 在"数据集管理"页面查看
6. 其他模块可以选择使用
```

**数据位置**:
- 前端: 数据集列表页面
- 后端: `/api/test-data/datasets`
- 存储: JSON文件或数据库

**数据集结构**:
```json
{
  "id": "dataset_001",
  "name": "用户注册数据集",
  "description": "包含10个用户注册测试数据",
  "api_id": "api_123",
  "data": [
    {"username": "张三", "email": "zhangsan@test.com"},
    {"username": "李四", "email": "lisi@test.com"}
  ],
  "created_at": "2024-03-20",
  "version": "1.0"
}
```

---

### 阶段4: Test Cases集成 (⏳ P1.4 集成2)
**功能**: 测试用例可以关联数据集

```
测试用例流程:
1. 创建/编辑测试用例
2. 点击"选择测试数据"
3. 从数据集列表中选择
4. 数据集绑定到测试用例
5. 执行测试时自动使用数据
```

**数据位置**:
- 前端: TestCases页面
- 后端: `/api/test-cases`
- 关联: `test_case.dataset_id`

**测试用例结构**:
```json
{
  "id": "tc_001",
  "name": "用户注册-正常流程",
  "api_id": "api_123",
  "dataset_id": "dataset_001",  // 关联的数据集
  "steps": [...],
  "assertions": [...]
}
```

---

### 阶段5: Automation集成 (⏳ P1.4 集成4)
**功能**: 自动化脚本中使用测试数据

```
自动化脚本流程:
1. 生成自动化脚本
2. 脚本中自动插入数据生成代码
3. 执行脚本时动态生成数据
4. 使用数据进行测试
```

**生成的脚本示例**:
```python
# 自动生成的测试脚本
import requests
from test_data import factory

# 生成测试数据
user_data = factory.user()
# 输出: {"username": "张三", "email": "zhangsan@test.com", ...}

# 使用数据测试API
response = requests.post(
    'https://api.example.com/users',
    json=user_data
)

assert response.status_code == 201
```

**数据位置**:
- 前端: Automation页面
- 后端: 脚本生成器
- 运行时: 动态生成
