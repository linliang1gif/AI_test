## 🆕 新增核心模块

### 1. Swagger/OpenAPI自动解析模块
**路径**: `app/api_parser/`

**核心文件**:
- `swagger_api_parser.py` - Swagger/OpenAPI解析器
- `openapi_parser.py` - OpenAPI专用解析器

**功能特性**:
- ✅ 支持Swagger 2.x和OpenAPI 3.x
- ✅ 自动解析接口路径、方法、参数
- ✅ 提取请求体和响应结构
- ✅ 生成标准化接口数据
- ✅ 支持JSON和YAML格式

**输出结构**:
```json
{
  "endpoint": "/api/login",
  "method": "POST", 
  "params": [
    {"name": "username", "type": "string"},
    {"name": "password", "type": "string"}
  ],
  "request_body": {...},
  "responses": {...}
}
```

### 2. 接口自动化脚本生成模块
**路径**: `app/api_test_generator/`

**核心文件**:
- `api_test_generator.py` - API测试生成器
- `test_case_builder.py` - 测试用例构建器

**功能特性**:
- ✅ 自动生成pytest测试脚本
- ✅ 包含正常请求测试
- ✅ 参数缺失测试
- ✅ 非法参数测试
- ✅ 权限测试
- ✅ 边界测试

**生成示例**:
```python
def test_login_success():
    response = requests.post("/api/login", 
                           json={"username":"test","password":"123456"})
    assert response.status_code == 200

def test_login_missing_username():
    response = requests.post("/api/login", 
                           json={"password":"123456"})
    assert response.status_code == 400
```

### 3. Self Healing自修复模块
**路径**: `app/self_healing/`

**核心文件**:
- `self_healing_engine.py` - 自修复引擎
- `error_analyzer.py` - 错误分析器
- `code_fixer.py` - 代码修复器

**功能特性**:
- ✅ pytest执行失败后自动分析
- ✅ AI智能生成修复代码
- ✅ 自动应用修复并重试
- ✅ 支持最大重试次数配置
- ✅ 完整的修复历史记录

**工作流程**:
1. pytest执行失败
2. 收集错误日志
3. AI分析错误原因
4. 生成修复代码
5. 自动应用修复
6. 重新执行pytest
7. 循环直到成功或达到最大重试次数
