## 🔨 需要的修复

### 1. 后端集成Ollama

后端当前使用 `get_enhanced_ai_client`，需要确认是否支持Ollama。

**建议修改**:
```python
# backend_api_server.py
from ai.ai_client import get_ai_client

# 使用Ollama
client = get_ai_client(use_ollama=True)
```

### 2. 前端添加Ollama选项

前端AI提供商选择器需要添加Ollama选项。

**建议添加**:
```javascript
const providers = [
  { id: 'ollama', name: 'Ollama (本地)', icon: '🤖' },
  { id: 'deepseek', name: 'DeepSeek', icon: '🧠' },
  { id: 'openai', name: 'OpenAI', icon: '🤖' }
]
```
