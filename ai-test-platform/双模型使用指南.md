## 🤖 模型特点对比

### qwen2.5:1.5b (轻量级模型)
- **大小**: 986 MB
- **响应速度**: 快 (3-20秒)
- **内存占用**: 低 (~2GB RAM)
- **适用场景**:
  - 测试用例生成
  - 简单分析和总结
  - 快速问答
  - 基础文档解析

### qwen2.5-coder:latest (代码专用模型)
- **大小**: 4.7 GB  
- **响应速度**: 慢 (10-60秒)
- **内存占用**: 高 (~4-6GB RAM)
- **适用场景**:
  - 复杂代码生成
  - API脚本生成
  - 代码审查和调试
  - 详细技术分析

## 🚀 使用方法

### 1. 在Python代码中使用

```python
from ai.enhanced_ai_client import EnhancedAIClient

# 创建客户端
client = EnhancedAIClient()

# 自动选择模型 - 测试用例生成
response = client.generate_text(
    "请生成一个用户注册API的测试用例",
    provider='ollama',
    task_type='test_case_generation'
)

# 自动选择模型 - 代码生成  
response = client.generate_text(
    "请用Python写一个API测试脚本",
    provider='ollama',
    task_type='code_generation'
)

# 优先速度
response = client.generate_text(
    "快速分析这个错误",
    provider='ollama',
    prefer_speed=True
)
```

### 2. 直接使用模型选择器

```python
from model_selector import ModelSelector

selector = ModelSelector()

# 自动选择并生成
result = selector.generate_with_auto_selection(
    prompt="请生成一个登录API的测试用例",
    task_type="test_case_generation"
)

print(f"使用模型: {result['model_used']}")
print(f"生成内容: {result['content']}")
```

### 3. 在Web界面中使用

1. 访问 **AI Insights** 页面
2. 选择 **Ollama** 作为AI提供商
3. 系统会自动根据任务类型选择模型
4. 在高级设置中可以手动指定模型

## ⚡ 性能优化建议

### 内存管理
```bash

# 停止不需要的模型释放内存
```

### 并发控制
- 同时只运行一个大模型
- 轻量级模型可以并发运行
- 避免同时处理多个复杂任务

### 任务分配策略
1. **简单任务优先**: 使用轻量级模型快速处理
2. **复杂任务批处理**: 集中使用大模型处理
3. **混合策略**: 根据实际需求动态调整

## 🛠️ 故障排除

### 常见问题

#### 1. 大模型超时
**现象**: qwen2.5-coder:latest 响应超时
**解决**: 系统自动回退到轻量级模型

#### 2. 内存不足
**现象**: 模型加载失败
**解决**: 
```bash
# 停止大模型
ollama stop qwen2.5-coder:latest

# 只使用轻量级模型
export OLLAMA_DEFAULT_MODEL=qwen2.5:1.5b
```

#### 3. 响应质量不满意
**解决**: 
- 简单任务: 使用 qwen2.5:1.5b
- 复杂任务: 强制使用 qwen2.5-coder:latest
- 调整 temperature 参数
