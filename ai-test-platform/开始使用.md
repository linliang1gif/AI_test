## 💡 三种AI模式

### 1. Ollama本地模型（推荐）
```python
from ai.ai_client import get_ai_client
client = get_ai_client(use_ollama=True)
response = client.generate_text("你的提示词")
```

### 2. Mock模式（快速测试）
```python
from ai.ai_client import get_ai_client
client = get_ai_client(use_mock=True)
response = client.generate_text("你的提示词")
```

### 3. 云端API（生产环境）
```python
from ai.ai_client import get_ai_client
client = get_ai_client(provider="deepseek")
response = client.generate_text("你的提示词")
```
