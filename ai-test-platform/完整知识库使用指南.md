# 完整知识库使用指南

## 🎯 概述

AI测试平台现在拥有完整的系统知识:
- ✅ **814个API接口** (Swagger文档)
- ✅ **500个前端文件** (Vue + JavaScript)
- ✅ **500个后端文件** (Java + XML)
- ✅ **总计1814个知识条目**

---

## 📚 知识库结构

### 1. API知识库 (apis)
- **来源**: Swagger JSON文档
- **内容**: API路径、方法、参数、响应
- **用途**: 理解接口定义,生成API测试

### 2. 前端代码库 (frontend_code)
- **来源**: 前端代码目录
- **内容**: Vue组件、JavaScript文件、路由配置
- **用途**: 理解前端实现,生成UI测试

### 3. 后端代码库 (backend_code)
- **来源**: 后端代码目录
- **内容**: Java类、Service、Controller、Mapper
- **用途**: 理解业务逻辑,生成集成测试

## 🔍 知识库查询示例

### 查询API

```python
from knowledge.knowledge_manager import KnowledgeManager

km = KnowledgeManager()
collection = km.kb.get_collection("apis")

# 查询采购相关API
results = collection.query(
    query_texts=["采购订单 新增 查询"],
    n_results=5
)

for metadata in results['metadatas'][0]:
    print(f"{metadata['method']} {metadata['path']}")
    print(f"摘要: {metadata['summary']}")
```

### 查询前端代码

```python
collection = km.kb.get_collection("frontend_code")

# 查询登录组件
results = collection.query(
    query_texts=["用户登录 Login组件"],
    n_results=3
)

for metadata in results['metadatas'][0]:
    print(f"文件: {metadata['filename']}")
    print(f"路径: {metadata['path']}")
    print(f"语言: {metadata['language']}")
```

### 查询后端代码

```python
collection = km.kb.get_collection("backend_code")

# 查询采购订单Service
results = collection.query(
    query_texts=["采购订单 PurchaseOrderService"],
    n_results=3
)

for metadata in results['metadatas'][0]:
    print(f"文件: {metadata['filename']}")
    print(f"类: {metadata.get('classes', 'N/A')}")
    print(f"包: {metadata.get('package', 'N/A')}")
```
