### 背景
开发团队刚刚完成支付模块的微信支付和支付宝支付功能，需要快速验证是否正常。

### 操作步骤

**第1步: 打开AI测试控制台**
```
浏览器访问: http://localhost:5173/ai-test-console
```

**第2步: 输入需求描述**
```
支付模块新增微信支付和支付宝支付功能，包含支付、退款、查询接口
```

**第3步: 输入Git Diff（可选）**
```python
+def wechat_pay(order_id, amount):
+    """微信支付"""
+    return process_payment('wechat', order_id, amount)
+
+def alipay_pay(order_id, amount):
+    """支付宝支付"""
+    return process_payment('alipay', order_id, amount)
+
+def refund_payment(order_id):
+    """退款"""
+    return process_refund(order_id)
```

**第4步: 选择优先级**
```
点击 [P0] 按钮（核心功能）
```

**第5步: 执行测试**
```
点击 "🚀 Run AI Test" 按钮
```
