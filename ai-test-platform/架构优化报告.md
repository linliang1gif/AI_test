### 2. 简化Pytest技能
**文件**: `ai_core/skills/pytest_skill.py`

**优化前**: 147行，包含重试、覆盖率等复杂功能
**优化后**: 40行，只保留核心功能

```python
class PytestSkill:
    def run(self, script_path):
        try:
            result = self.runner.run_tests(script_path)
            return {
                "success": result.get("success", False),
                "result": result,
                "error": result.get("error", "")
            }
        except Exception as e:
            return {
                "success": False,
                "result": {},
                "error": str(e)
            }
```

**优点**:
- ✅ 代码量减少73%
- ✅ 更易维护
- ✅ 符合单一职责原则
