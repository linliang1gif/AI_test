## 需要实现的功能

### 功能1: 生成自动化脚本

**前端**: TestCases.jsx
- 在操作列添加"生成脚本"按钮
- 点击后调用后端API生成pytest脚本
- 显示生成的脚本代码
- 支持下载脚本文件

**后端**: backend_api_server.py
- 新增 `/api/testcases/{id}/generate-script` 接口
- 调用 `automation/api_script_generator.py`
- 根据测试用例生成pytest脚本
- 包含断言、测试数据、请求代码

**示例脚本**:
```python
def test_订单列表排序():
    """验证订单列表排序功能"""
    # 测试数据
    data = {"sort": "desc", "field": "created_at"}
    
    # 发送请求
    response = requests.get("/api/orders", params=data)
    
    # 断言
    assert response.status_code == 200
    assert len(response.json()["data"]) > 0
```

---

### 功能2: 执行测试

**前端**: TestCases.jsx
- 在操作列添加"执行测试"按钮
- 点击后调用后端执行测试
- 显示执行进度
- 更新测试状态

**后端**: backend_api_server.py
- 新增 `/api/testcases/{id}/execute` 接口
- 调用 `executor/real_test_executor.py`
- 执行测试脚本
- 返回执行结果

**执行结果**:
```json
{
  "success": true,
  "status": "passed",
  "duration": 1.23,
  "assertions": {
    "total": 3,
    "passed": 3,
    "failed": 0
  },
  "logs": "..."
}
```

---

### 功能3: 测试执行记录

**数据模型**:
```python
test_runs_db = [
    {
        "id": 1,
        "testcase_id": 1,
        "status": "passed",
        "duration": 1.23,
        "executed_at": "2024-03-21 10:30:00",
        "logs": "...",
        "assertions": {...}
    }
]
```

**前端**: TestRuns.jsx
- 展示所有测试执行记录
- 按时间倒序排列
- 支持筛选和搜索
- 查看详细日志

**后端**: backend_api_server.py
- `/api/test-runs` - 获取执行记录
- `/api/test-runs/{id}` - 获取单条记录详情

---

### 功能4: 测试报告生成

**前端**: Reports.jsx
- 展示测试统计数据
- 通过率、失败率图表
- AI分析失败原因
- 生成PDF报告

**后端**: backend_api_server.py
- `/api/reports/generate` - 生成测试报告
- 调用 `report/report_generator.py`
- AI分析测试结果
- 生成可视化报告
