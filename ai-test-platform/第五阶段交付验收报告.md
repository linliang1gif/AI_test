### 功能1: 流程编排

**要求**: 串联5个模块，不写业务逻辑

**实现**:
```python
# 1. 调用 Agent
decision = agent_service.analyze(...)

# 2. 调用 Strategy
strategy = strategy_service.generate_strategy(decision)

# 3. 调用 Orchestrator
execution = orchestrator_service.run(strategy)

# 4. 调用 Self-Healing（条件触发）
if failed_count > 0:
    healing = healing_service.fix_and_retry(...)

# 5. 生成 Report
report = generate_report(...)
```
