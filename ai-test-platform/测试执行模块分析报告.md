## 📋 需要实现的功能

### 1. 获取测试运行列表
**端点**: `GET /api/test-runs`
**功能**: 返回所有测试运行记录

### 2. 启动新的测试运行
**端点**: `POST /api/test-runs`
**功能**: 
- 创建新的测试运行任务
- 在后台执行测试用例
- 返回任务ID供前端轮询

### 3. 获取测试运行状态
**端点**: `GET /api/test-runs/{id}/status`
**功能**:
- 返回测试运行的实时状态
- 包含进度、结果、日志等信息

### 4. 控制测试运行
**端点**: 
- `POST /api/test-runs/{id}/pause` - 暂停
- `POST /api/test-runs/{id}/stop` - 停止
- `POST /api/test-runs/{id}/resume` - 恢复

## 💡 实现方案

### 数据结构
```python
test_run = {
    "id": 1,
    "name": "测试运行 #1",
    "status": "running",  # running, completed, failed, paused
    "environment": "staging",
    "progress": 45,
    "totalTests": 10,
    "passed": 4,
    "failed": 1,
    "pending": 5,
    "duration": "2m 30s",
    "startTime": "2024-01-15 10:30:00",
    "endTime": null,
    "logs": []
}
```

### 执行流程
1. 前端发起测试运行请求
2. 后端创建test_run记录
3. 后台任务执行测试用例
4. 实时更新test_run状态
5. 前端轮询获取最新状态
6. 显示执行进度和结果
