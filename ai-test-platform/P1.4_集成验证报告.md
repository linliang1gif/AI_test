## 📝 使用指南

### 步骤1: 打开前端
```
浏览器访问: http://localhost:5174/
```

### 步骤2: 进入API管理
点击左侧导航栏的 "🌐 API管理"

### 步骤3: 上传Swagger文档
1. 点击 "📁 文件上传" 标签
2. 选择文件: `ai测试/ai-test-platform/sample_swagger.json`
3. 等待解析完成

### 步骤4: 查看测试数据按钮
上传成功后,每个API右侧会显示:
```
🏭 测试数据
```

### 步骤5: 生成测试数据
1. 点击 "🏭 测试数据" 按钮
2. 查看API参数信息
3. 点击 "🎲 生成数据"
4. 查看生成的测试数据
5. 点击 "✅ 使用此数据"

## 🎯 示例API

已在 `sample_swagger.json` 中包含4个示例API:

### 1. POST /api/users - 创建用户
参数:
- username: string
- email: string
- password: string
- age: integer

### 2. GET /api/users/{id} - 获取用户信息
参数:
- id: integer (路径参数)

### 3. POST /api/orders - 创建订单
参数:
- user_id: integer
- product_id: integer
- quantity: integer
- total_price: number

### 4. GET /api/products - 获取产品列表
参数:
- page: integer
- page_size: integer
- category: string

## 🎨 功能特点

### 智能识别
- 自动解析API参数类型

- 支持中文姓名、邮箱等
