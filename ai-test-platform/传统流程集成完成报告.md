## 🎯 核心特性

### 1. 基于 Context 的编排

所有模块只操作 context，实现完全解耦：

```python
# Pipeline V2 核心流程
context = {}
context["decision"] = agent.analyze()
context["strategy"] = strategy.generate()

if config.USE_CASE_GENERATOR:
    context["cases"] = case.generate()
else:
    context["cases"] = None

context["execution"] = orchestrator.run(context)
context["healing"] = healing.run(context)
context["report"] = report.generate(context)
```

### 2. 可插拔架构

通过配置控制流程：

```python
# 启用 Case Generator
pipeline.run_pipeline({
    "requirement": "...",
    "use_case_generator": True
})

# 禁用 Case Generator（使用策略模式）
pipeline.run_pipeline({
    "requirement": "...",
    "use_case_generator": False
})
```

### 3. 双模式执行

Orchestrator V2 支持两种执行模式：

**模式1: 基于用例（新）**
```python
orchestrator.run(strategy, cases=case_result)
# 执行模式: "cases"
# 返回用例级别结果
```

**模式2: 基于策略（原）**
```python
orchestrator.run(strategy, cases=None)
# 执行模式: "strategy"
# 返回模块级别结果
```

### 4. 完整的数据流

```
需求文档
    ↓
Agent V3 (解析 + 决策)
    ↓ parsed_modules
Strategy Engine
    ↓ strategy
Case Generator (可选)
    ↓ cases
Orchestrator V2
    ↓ execution (含 case_results)
Self-Healing
    ↓ healing
Report
    ↓ report
```

## 📝 使用示例

### 示例1: 启用 Case Generator（推荐）

```python
from pipeline.pipeline_service import get_pipeline_service

pipeline_service = get_pipeline_service()

result = pipeline_service.run_pipeline({
    "requirement": "需求文档...",
    "git_diff": "代码变更...",
    "use_case_generator": True  # 启用
})

# 查看用例级别结果
for module_result in result['execution']['results']:
    case_results = module_result.get('case_results', [])
    for case in case_results:
        print(f"{case['title']}: {case['status']}")
```

### 示例2: 禁用 Case Generator（快速模式）

```python
result = pipeline_service.run_pipeline({
    "requirement": "需求文档...",
    "git_diff": "代码变更...",
    "use_case_generator": False  # 禁用
})

# 使用策略模式执行
print(f"执行模式: {result['execution']['mode']}")  # "strategy"
```

### 示例3: 通过 API 调用

```python
import requests

response = requests.post("http://localhost:8000/api/pipeline/run", json={
    "requirement": "需求文档...",
    "git_diff": "代码变更...",
    "use_case_generator": True
})

result = response.json()
print(f"Trace ID: {result['trace_id']}")
print(f"用例数: {result['cases']['total_cases']}")
```
