# 自动化脚本按钮使用说明

## 问题诊断

如果点击按钮没有反应,请按以下步骤排查:

### 1. 检查后端服务状态 ✅

后端API已验证正常工作:
- ✅ 运行脚本API正常
- ✅ 下载脚本API正常  
- ✅ 生成脚本API正常
- ✅ 任务状态查询正常

### 2. 检查前端代码 ✅

前端代码已优化:
- ✅ 添加了console.log调试日志
- ✅ 改进了错误处理
- ✅ 添加了更详细的反馈消息
- ✅ 自动刷新脚本列表

### 3. 浏览器调试步骤

#### 打开开发者工具
1. 按 `F12` 或 `Ctrl+Shift+I` 打开开发者工具
2. 切换到 `Console` 标签页

#### 查看日志输出
点击按钮时应该看到:
```
运行脚本: {id: 1, name: "test_user_authentication.py", ...}
响应状态: 200
执行响应: {success: true, taskId: "script_1_...", message: "..."}
```

#### 查看网络请求
1. 切换到 `Network` 标签页
2. 点击按钮
3. 查看是否有对应的HTTP请求
4. 检查请求状态码和响应内容

### 4. 常见问题和解决方案

#### 问题1: 点击按钮完全没反应
**可能原因**:
- 事件处理器没有正确绑定
- JavaScript错误导致代码中断

**解决方案**:
1. 查看Console是否有错误信息
2. 刷新页面 (Ctrl+R)
3. 清除浏览器缓存 (Ctrl+Shift+Delete)
4. 硬刷新 (Ctrl+Shift+R)

#### 问题2: 有请求但没有反馈
**可能原因**:
- alert被浏览器拦截
- 响应处理逻辑有问题

**解决方案**:
1. 检查浏览器是否拦截了弹窗
2. 查看Console的日志输出
3. 查看Network标签的响应内容

#### 问题3: 请求失败
**可能原因**:
- 后端服务未启动
- CORS跨域问题
- 网络连接问题

**解决方案**:
1. 确认后端服务运行在 http://127.0.0.1:8081
2. 检查后端日志是否收到请求
3. 检查Network标签的错误信息

## 正确的使用流程

### 1. 运行脚本
```
1. 在脚本列表中找到要运行的脚本
2. 点击脚本卡片上的"运行"按钮 (▶️图标)
3. 等待弹窗提示: "✅ 开始执行脚本..."
4. 查看Console日志确认执行状态
5. 等待5-10秒后刷新页面查看结果
```

**预期效果**:
- 弹出提示框显示任务ID
- Console显示执行日志
- 脚本状态更新为"completed"

### 2. 下载脚本
```
1. 在脚本列表中找到要下载的脚本
2. 点击脚本卡片上的"下载"按钮 (⬇️图标)
3. 浏览器会打开新标签页或下载文件
```

**预期效果**:
- 浏览器下载pytest脚本文件
- 或在新标签页显示脚本内容

### 3. 生成新脚本
```
1. 在右侧"生成设置"面板中:
   - 选择测试框架 (pytest/unittest/selenium)
   - 选择编程语言 (Python/JavaScript/Java)
   - 选择测试类型 (API Tests/UI Tests/Integration Tests)
2. 点击"生成新脚本"按钮
3. 等待弹窗提示: "✅ 自动化脚本生成任务已启动..."
4. 等待5秒后自动刷新脚本列表
```

**预期效果**:
- 弹出提示框显示任务ID
- Console显示生成进度
- 5秒后脚本列表自动刷新
- 新脚本出现在列表中

## 前端代码优化说明

### 已添加的改进

#### 1. 运行脚本按钮
```javascript
const handleRunScript = (script) => {
  console.log('运行脚本:', script)  // 添加日志
  
  fetch(url, { 
    method: 'POST',
    headers: { 'Content-Type': 'application/json' }  // 添加headers
  })
    .then(r => {
      console.log('响应状态:', r.status)  // 添加日志
      if (!r.ok) throw new Error(`HTTP ${r.status}`)  // 错误处理
      return r.json()
    })
    .then(data => {
      console.log('执行响应:', data)  // 添加日志
      if (data.success) {
        alert(`✅ ${data.message}\n任务ID: ${data.taskId}`)  // 详细提示
        // 刷新脚本列表
        automationAPI.getScripts()
          .then(d => setScripts(d.scripts || []))
      }
    })
}
```

#### 2. 生成脚本按钮
```javascript
const handleGenerateScript = () => {
  console.log('生成脚本参数:', { framework, language, testType })  // 添加日志
  
  fetch(url, { ... })
    .then(data => {
      if (data.success) {
        alert(`✅ ${data.message}\n任务ID: ${data.taskId}\n\n请稍等3-5秒后刷新查看新脚本`)
        // 延迟刷新,等待脚本生成完成
        setTimeout(() => {
          automationAPI.getScripts()
            .then(d => setScripts(d.scripts || []))
        }, 5000)
      }
    })
}
```

## 如果问题仍然存在

### 1. 重启服务
```bash
# 停止前端
Ctrl+C (在前端终端)

# 停止后端
Ctrl+C (在后端终端)

# 重新启动
cd ai测试/ai-test-platform
npm run dev  # 前端
py backend_api_server.py  # 后端
```

### 2. 清除浏览器缓存
```
1. 按 Ctrl+Shift+Delete
2. 选择"缓存的图片和文件"
3. 点击"清除数据"
4. 刷新页面 (Ctrl+Shift+R)
```

### 3. 使用无痕模式
```
1. 按 Ctrl+Shift+N (Chrome) 或 Ctrl+Shift+P (Firefox)
2. 访问 http://localhost:3000
3. 测试按钮功能
```

### 4. 检查浏览器兼容性
推荐使用:
- Chrome 90+
- Firefox 88+
- Edge 90+
