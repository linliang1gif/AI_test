## 🚀 快速使用指南

### 第一次使用

```bash
# 1. 克隆项目
git clone <repository-url>
cd ai-test-platform

# 2. 安装依赖
pip install -r requirements.txt
cd frontend && npm install && cd ..

# 3. 配置环境
cp .env.example .env
# 编辑.env文件

# 4. 健康检查
python health_check.py

# 5. 启动平台
python start_platform.py
```

### 日常使用

```bash
# 启动平台
python start_platform.py

# 健康检查
python health_check.py

# 停止平台
# 按 Ctrl+C
```
