# 真实测试执行使用指南

## 🚀 快速开始

### 1. 安装依赖

```bash
# 进入项目目录
cd ai-test-platform

# 安装基础依赖
pip install requests

# 安装pytest支持(可选,用于脚本执行)
pip install pytest pytest-json-report
```

### 2. 集成真实执行器(可选)

如果需要手动集成,运行:
```bash
py integrate_real_executor.py
```

### 3. 重启后端服务器

```bash
# 停止当前服务器(Ctrl+C)
# 重新启动
py backend_api_server.py
```

### 4. 测试功能

访问 http://localhost:3000/test-runs 并点击"运行新测试"

## 📋 测试用例准备

### 方式1: API测试用例

**从API Explorer生成**:
1. 进入"API Explorer"页面
2. 导入Swagger文档或手动添加API
3. 选择API,点击"生成测试用例"
4. 测试用例自动标记为`api_generated`

**测试用例格式**:
```json
{
  "id": 1,
  "title": "GET /api/users - 获取用户列表",
  "source": "api_generated",
  "api_id": 1,
  "steps": ["发送GET请求", "验证响应"],
  "expected": "返回200状态码"
}
```

**执行效果**:
- 真实发送HTTP请求
- 验证响应状态码
- 记录响应时间
- 显示详细日志

### 方式2: 自动化脚本测试

**从Automation模块生成**:
1. 进入"自动化脚本"页面
2. 生成pytest脚本
3. 在测试用例中关联脚本

**测试用例格式**:
```json
{
  "id": 2,
  "title": "用户登录功能测试",
  "script_path": "output/scripts/test_login.py",
  "steps": ["执行pytest脚本"],
  "expected": "所有测试通过"
}
```

**执行效果**:
- 调用pytest执行脚本
- 解析测试结果
- 统计通过/失败数量
- 显示执行日志

### 方式3: AI生成测试用例

**从测试用例模块生成**:
1. 进入"测试用例"页面
2. 上传需求文档
3. AI自动生成测试用例

**测试用例格式**:
```json
{
  "id": 3,
  "title": "用户注册功能测试",
  "source": "ai_generated",
  "steps": ["打开注册页面", "填写信息", "提交"],
  "expected": "注册成功"
}
```

**执行效果**:
- 智能识别测试类型
- 如果包含API关键词,尝试API测试
- 否则模拟执行
- 记录执行日志

## 🐛 故障排查

### 问题1: 显示"模拟执行"而不是"真实执行"

**原因**: 真实测试执行器未正确导入

**解决**:
1. 检查文件是否存在: `executor/real_test_executor.py`
2. 检查Python路径
3. 运行集成脚本: `py integrate_real_executor.py`
4. 重启后端服务器

### 问题2: API测试失败 - 连接错误

**原因**: 目标服务器未运行或URL错误

**解决**:
1. 确认目标服务器运行中
2. 检查base_url配置
3. 测试网络连接: `curl http://localhost:8080/api/users`
4. 检查防火墙设置

### 问题3: pytest执行失败

**原因**: pytest未安装

**解决**:
```bash
pip install pytest pytest-json-report
```

### 问题4: 所有测试显示"pending"

**原因**: 测试用例类型未正确识别

**解决**:
1. 检查测试用例的`source`字段
2. 对于API测试,确保`source='api_generated'`
3. 对于脚本测试,确保有`script_path`字段
4. 查看后端日志了解详情

### 添加自定义验证

**修改**: `executor/real_test_executor.py`

```python
def validate_api_response(self, response, test_case):
    """自定义API响应验证"""
    expected = test_case.get('expected_response', {})
    
    # 验证状态码
    if 'status_code' in expected:
        assert response.status_code == expected['status_code']
    
    # 验证响应头
    if 'headers' in expected:
        for key, value in expected['headers'].items():
            assert response.headers.get(key) == value
    
    # 验证响应体
    if 'body_contains' in expected:
        assert expected['body_contains'] in response.text
    
    # 验证JSON字段
    if 'json_fields' in expected:
        data = response.json()
        for field, value in expected['json_fields'].items():
            assert data.get(field) == value
```
