## 🎯 功能使用说明

### Tab 1: 📊 基础生成

**功能**: 快速生成各种类型的测试数据

**使用步骤**:
1. 选择数据类型(用户/订单/产品/地址/支付/库存)
2. 设置生成数量(1-100)
3. 点击"生成数据"按钮
4. 查看生成的数据和质量评分

**示例**:
- 生成1个用户: 选择"用户" → 数量1 → 生成
- 批量生成10个产品: 选择"产品" → 数量10 → 生成

**生成的数据包含**:
- 用户: ID、用户名、邮箱、手机、姓名、年龄、性别、状态、时间戳
- 订单: 订单ID、用户ID、产品ID、数量、金额、状态、时间戳
- 产品: 产品ID、名称、分类、价格、库存、描述、状态、时间戳
- 地址: 地址ID、用户ID、省市区、详细地址、邮编、联系人、电话
- 支付: 支付ID、订单ID、金额、方式、状态、时间戳
- 库存: 库存ID、产品ID、仓库ID、数量、位置、时间戳

### Tab 2: 🧠 AI智能生成

**功能**: 基于上下文智能生成字段值

**使用步骤**:
1. 输入字段名(如: user_email, product_name)
2. (可选)添加上下文信息
3. 点击"智能生成"按钮
4. 查看AI生成的值

**示例**:
- 生成邮箱: 字段名 `user_email` → 生成 → 得到 `user1234@demo.com`
- 生成产品名: 字段名 `product_name` → 生成 → 得到 `产品ABC`
- 带上下文: 字段名 `user_email` + 上下文 `{"domain": "test.com"}` → 得到 `user@test.com`

**支持的字段类型**:
- ID类型: user_id, order_id, product_id
- 名称类型: username, product_name, company_name
- 邮箱类型: email, user_email, contact_email
- 电话类型: phone, mobile, telephone
- 日期类型: created_at, updated_at, birth_date
- 金额类型: price, amount, total
- 状态类型: status, state, is_active
- 描述类型: description, comment, note

### Tab 3: 🎯 测试场景

**功能**: 获取针对特定实体的测试场景建议

**使用步骤**:
1. 选择实体类型(用户/订单/产品/支付)
2. 点击"获取场景"按钮
3. 查看推荐的测试场景列表

**场景类型**:
- 🟢 正向场景(positive): 正常业务流程
- 🔴 负向场景(negative): 异常情况处理
- 🟡 边界场景(boundary): 边界值测试

**优先级**:
- 🔴 高优先级(high): 必须测试
- 🟡 中优先级(medium): 建议测试
- 🟢 低优先级(low): 可选测试

**示例场景**:
- 用户: 正常注册、重复邮箱注册、无效邮箱格式、密码强度测试
- 订单: 正常下单、库存不足、金额异常、并发下单
- 产品: 正常创建、价格边界、库存边界、分类验证
- 支付: 正常支付、余额不足、支付超时、重复支付

### Tab 4: 📈 统计信息

**功能**: 查看数据生成的统计信息

**显示内容**:
- 总生成次数
- 各字段使用频率
- 最近生成记录(最多10条)

**使用场景**:
- 了解哪些字段最常使用
- 查看最近的生成历史
- 分析数据生成模式

### Tab 5: 📋 模板管理

**功能**: 使用预定义模板快速生成数据

**使用步骤**:
1. 点击"加载模板"按钮
2. 查看可用模板列表
3. 选择模板并生成数据

**预定义模板**:
- 标准用户模板
- 测试订单模板
- 示例产品模板
- 默认地址模板

## 🔧 API调用示例

### 使用curl测试API

#### 1. 健康检查
```bash
curl http://localhost:8000/health
```

#### 2. 生成单个用户
```bash
curl -X POST http://localhost:8000/api/test-data/generate \
  -H "Content-Type: application/json" \
  -d '{"data_type": "user", "count": 1}'
```

#### 3. 批量生成产品
```bash
curl -X POST http://localhost:8000/api/test-data/generate \
  -H "Content-Type: application/json" \
  -d '{"data_type": "product", "count": 5}'
```

#### 4. AI智能生成
```bash
curl -X POST http://localhost:8000/api/test-data/smart-generate \
  -H "Content-Type: application/json" \
  -d '{"field_name": "user_email", "context": {"domain": "test.com"}}'
```

#### 5. 获取测试场景
```bash
curl http://localhost:8000/api/test-data/scenarios/user
```

#### 6. 数据质量评估
```bash
curl -X POST http://localhost:8000/api/test-data/evaluate \
  -H "Content-Type: application/json" \
  -d '{"data": {"user_id": "123", "email": "test@example.com", "age": 25}}'
```

#### 7. 获取边界值
```bash
curl "http://localhost:8000/api/test-data/boundary-values/integer?min_value=0&max_value=100"
```

#### 8. 获取非法值
```bash
curl http://localhost:8000/api/test-data/invalid-values/email
```

### 使用Python调用API

```python
import requests
import json

BASE_URL = "http://localhost:8000"

# 生成用户数据
response = requests.post(
    f"{BASE_URL}/api/test-data/generate",
    json={"data_type": "user", "count": 1}
)
user_data = response.json()
print(json.dumps(user_data, indent=2, ensure_ascii=False))

# AI智能生成
response = requests.post(
    f"{BASE_URL}/api/test-data/smart-generate",
    json={"field_name": "user_email", "context": {"domain": "test.com"}}
)
email = response.json()
print(f"生成的邮箱: {email['value']}")

# 获取测试场景
response = requests.get(f"{BASE_URL}/api/test-data/scenarios/user")
scenarios = response.json()
print(f"测试场景数量: {scenarios['count']}")
```

## 📊 数据质量评估

系统会自动对生成的数据进行4维度质量评估:

### 1. 完整性 (Completeness)
- 检查必填字段是否存在
- 检查字段值是否为空

### 2. 有效性 (Validity)
- 验证数据格式是否正确
- 验证数据类型是否匹配

### 3. 一致性 (Consistency)
- 检查关联字段的一致性
- 验证业务规则的一致性

### 4. 合理性 (Reasonableness)
- 检查数值范围是否合理
- 验证业务逻辑是否合理

**评分标准**:
- 90-100分: 优秀 (excellent) 🟢
- 70-89分: 良好 (good) 🟡
- 50-69分: 一般 (fair) 🟠
- 0-49分: 差 (poor) 🔴

## 🎨 高级功能

### 1. 自定义覆盖值

在生成数据时,可以覆盖默认值:

```json
{
  "data_type": "user",
  "count": 1,
  "overrides": {
    "age": 30,
    "gender": "female",
    "status": "active"
  }
}
```

### 2. 上下文感知生成

提供上下文信息以生成更符合场景的数据:

```json
{
  "field_name": "user_email",
  "context": {
    "domain": "company.com",
    "country": "CN",
    "department": "IT"
  }
}
```

### 3. 批量质量评估

一次评估多条数据的质量:

```json
{
  "data_list": [
    {"user_id": "1", "email": "test1@example.com"},
    {"user_id": "2", "email": "test2@example.com"},
    {"user_id": "3", "email": "test3@example.com"}
  ]
}
```

## 🐛 常见问题

### Q1: 前端无法连接后端
**A**: 确保后端服务器正在运行,检查端口8000是否被占用

### Q2: 生成的数据不符合预期
**A**: 使用overrides参数自定义字段值,或提供更详细的上下文信息

### Q3: API返回503错误
**A**: 测试数据工厂模块未正确加载,检查test_data目录和依赖

### Q4: 前端显示空白页面
**A**: 检查浏览器控制台错误,确保antd依赖已安装: `npm install antd @ant-design/icons`

### Q5: 数据质量评分过低
**A**: 检查生成的数据是否包含所有必填字段,字段格式是否正确
