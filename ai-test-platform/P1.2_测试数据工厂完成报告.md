## 🚀 快速开始

### 基础使用
```python
from test_data.data_factory import factory

# 基础数据
email = factory.email()
phone = factory.phone()
name = factory.chinese_name()

# 业务对象
user = factory.user()
order = factory.order()
product = factory.product()

# Mock数据
response = factory.api_response(success=True, data={"id": 1})
token = factory.jwt_token(user_id="123")
```

### 批量生成
```python
# 批量生成用户
users = factory.batch("user", 10)

# 批量生成产品
products = factory.batch("product", 5)
```

### 模板使用
```python
# 使用预定义模板
login_data = factory.from_template("user_login", 
                                   username="test", 
                                   password="123456")

# 注册自定义模板
factory.register_template("my_template", {...})
```

### 依赖管理
```python
# 自动处理依赖
order = factory.with_dependencies("order")

# 使用依赖链
result = factory.chain().add("user").add("product").add("order").execute()
```
