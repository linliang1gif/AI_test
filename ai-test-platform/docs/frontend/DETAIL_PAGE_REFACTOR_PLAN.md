# 详情页面深度重构计划

## 重构目标
将所有详情页面从原型化改造为商用级B端管理系统标准

## 重构范围
1. 测试用例详情页
2. 测试报告详情页  
3. 项目设置/详情页
4. API详情页
5. 测试执行详情页

## 设计规范

### 1. 布局结构
- **顶部区域**：面包屑导航 + PageHeader（标题 + 操作按钮）
- **基本信息区**：卡片形式展示核心元数据
- **内容区域**：Tab标签页分类展示（详情/日志/历史等）
- **最大宽度**：1400px，居中显示
- **卡片间距**：24px

### 2. 样式规范
- **圆角**：统一6px
- **主文字色**：slate-900
- **次要文字色**：slate-600
- **边框色**：slate-200
- **主色调**：降低亮蓝色，使用slate-700作为主要按钮色

### 3. 组件规范
- **状态标签**：使用Badge组件，Success/Warning/Error三色
- **操作按钮**：主要操作平铺，危险操作收入下拉菜单
- **空状态**：所有列表必须有Empty占位
- **加载状态**：全局Loading + Toast提示

### 4. 元数据字段（必须包含）
- 创建人
- 创建时间
- 最后修改人
- 最后修改时间
- 版本号（如适用）
- 状态
- 所属项目/模块

## 实施步骤
1. 创建通用组件（PageHeader, DetailCard, StatusBadge）
2. 重构测试用例详情页
3. 重构测试报告详情页
4. 重构项目详情页
5. 统一样式和交互

## 技术栈
- React + Tailwind CSS
- Lucide React（图标库）
- React Router（路由）
