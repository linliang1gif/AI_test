## 二、认证鉴权体系

### 2.1 认证方式：Spring Security OAuth2 + JWT

**Token 类型：** Bearer Token (JWT)

**请求头格式：**
```
Authorization: Bearer eyJhbGci...
```

**后端解析流程 (LoginCheckFilter)：**
1. 从 `Authorization` Header 读取 token
2. 去掉 `Bearer ` 前缀
3. 解析 JWT (JWSObject) 获取用户信息：userId, user_name, mobile, email, supplierId, pin, realName, avatar, clientId
4. 检查 Redis 黑名单 (`oauth2:black:{jti}`)
5. 将用户信息 Base64 编码后写入 request attribute `X-Access-Token`
6. 后续 Controller 通过 `RequestUtils.getUserHeader()` 获取用户

### 2.2 OAuth2 Token 获取

**Dev 环境：**
```
POST https://dev-sso.szhibu.com/oauth/token
Authorization: Basic ZGV2X3VzZXJfY2VudGVyOjEyMzQ1Ng==
Content-Type: application/x-www-form-urlencoded

username=fibrelink&password=123456&grant_type=password&scope=all
```

**Test/SIT 环境：**
```
POST https://sit-sso.szhibu.com/oauth/token
Authorization: Basic c2l0X3VzZXJfY2VudGVyOjEyMzQ1Ng==
Content-Type: application/x-www-form-urlencoded

username=blueRecycle&password=123456&grant_type=password&scope=all
```

> Basic 认证值解码：
> - dev: `dev_user_center:123456`
> - sit: `sit_user_center:123456`

### 2.3 Token 有效期

## 三、统一响应结构

### 3.1 BaseResponse 格式

所有接口统一返回：
```json
{
  "code": 200,
  "message": "SUCCESS",
  "data": { ... }
}
```

Java 类：`com.sfabric.cloud.common.response.BaseResponse<T>`

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 业务状态码 |
| message | String | 响应信息 |
| data | T | 响应数据 |

### 3.2 业务状态码 (ResponseCode)

| code | 枚举名 | 含义 | 测试断言建议 |
|------|--------|------|-------------|
| **200** | OK | **成功** | ✅ 断言 code==200 表示业务成功 |
| 400 | BUSINESS_ERROR | 业务异常 | ❌ 失败 |
| 401 | AUTHORIZE_FAILED | 登录/认证失败 | ❌ 鉴权失败 |
| 402 | ILLEGAL_TOKEN | Token非法 | ❌ Token 格式错 |
| 405 | TOKEN_EXPIRE | Token已过期 | ❌ 需重新登录 |
| 406 | NO_USER_INFO | 用户不存在 | ❌ |
| 407 | LOGIN_OTHER_WHERE | 异地登录 | ❌ |
| 408 | ACCOUNT_BINDING_CONFLICT | 账号绑定冲突 | ❌ |
| 409 | ACCOUNT_NOT_BINDING | 账号未绑定 | ❌ |
| 410 | NO_THIRD_SYS_INFO | 第三方账号未授权 | ❌ |
| 2000 | NO_LOGIN | 用户未登录 | ❌ |
| 2001 | ACCOUNT_LOCKED | 账号被锁定 | ❌ |
| 2002 | ACCOUNT_DISABLED | 用户已失效 | ❌ |
| 2003 | ACCOUNT_EXPIRED | 账号已过期 | ❌ |
| 2004 | ACCOUNT_CREDENTIAL_EXPIRED | 凭证已过期 | ❌ |
| 4004 | NOT_FOUND | 资源不存在 | ❌ |
| 4005 | METHOD_NOT_ALLOWED | 方法不允许 | ❌ |
| 5000 | SYSTEM_ERROR | 服务器异常 | ❌ |
| 5100 | RPC_ERROR | 远程调用异常 | ❌ |
| 10000 | PARAM_ERROR | 参数不合法 | ❌ |
| 10001 | REPETITIVE_OPERATION | 重复操作 | ❌ |
| 99999 | API_GATEWAY_ERROR | 网关异常 | ❌ |

### 3.3 测试断言规则

```
✅ 通过条件：HTTP Status == 200 AND body.code == 200
❌ 失败条件：body.code != 200 (即使 HTTP 200)
⚠️ 特别注意：HTTP 200 + body.code 401/402/405 = 鉴权失败，不是接口成功
```

```

Scope：all
```

### 8.3 断言规则

```
HTTP Status == 200
AND body.code == 200
AND body.message == "SUCCESS" (可选)
```

失败判定（即使 HTTP 200）：
```
body.code == 401  → 认证失败
body.code == 402  → Token非法
body.code == 405  → Token过期
body.code == 400  → 业务异常
body.code == 10000 → 参数错误
```

