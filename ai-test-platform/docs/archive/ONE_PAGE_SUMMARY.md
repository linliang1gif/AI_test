# AI测试控制台 - 一页纸总结

## 🎯 是什么？
一个能在**10-20秒**内完成完整测试流程的Web界面，包含AI决策、策略生成、自动执行、智能修复、报告生成五个阶段。

## 🚀 怎么用？
1. 打开 http://localhost:5173/ai-test-console
2. 输入需求描述
3. 选择优先级（P0/P1/P2）

5. 查看结果（10-20秒）
