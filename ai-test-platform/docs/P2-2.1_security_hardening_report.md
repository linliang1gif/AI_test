## 一、/admin/app-mode 保护

### 1. 是否默认禁用？

**✅ 是。** 默认情况下 `/admin/app-mode` 返回 **403**。

### 2. 什么条件下允许调用？

满足以下**任意一个**条件即可：

| 条件 | 环境变量 |
|---|---|
| 测试模式 | `TESTING=true` |
| 显式启用 | `ENABLE_ADMIN_APP_MODE=true` |

### 3. real 模式下未启用时是否返回 403？

**✅ 是。** 无论 `APP_MODE` 是 `mock` 还是 `real`，只要未设置上述启用条件，一律返回 403：

```json
{
  "code": "ADMIN_APP_MODE_DISABLED",
  "message": "admin app-mode endpoint is disabled outside testing mode"
}
```

**验证记录**：

```
# 无 TESTING 环境变量：
PUT /admin/app-mode?mode=mock → 403 ADMIN_APP_MODE_DISABLED

# 有 TESTING=true：
PUT /admin/app-mode?mode=mock → 200 {"success": true, "app_mode": "mock"}
```

### 4. 测试脚本如何启用 admin app-mode？

| 场景 | 方式 |
|---|---|
| `run_regression_all.py` | 子进程环境自动注入 `TESTING=true` |
| `ci_local.bat` / `ci_local.sh` | 启动后端前设置 `TESTING=true` |
| `.github/workflows/ci.yml` | 全局 `env.TESTING: "true"` |
| 手动本地测试 | `set TESTING=true` 或 `export TESTING=true` 后启动后端 |
| 生产环境 | **不设置** → 端点被禁用 |

### 5. 修改的文件

| 文件 | 修改内容 |
|---|---|
| `backend/health.py` | `set_app_mode()` 添加 TESTING/ENABLE_ADMIN_APP_MODE 检查 |
| `scripts/run_regression_all.py` | 子进程 env 注入 `TESTING=true` |
| `scripts/ci_local.bat` | 启动后端前 `set TESTING=true` |
| `scripts/ci_local.sh` | 启动后端前 `export TESTING=true` |
| `.github/workflows/ci.yml` | 全局 env 添加 `TESTING: "true"` |
