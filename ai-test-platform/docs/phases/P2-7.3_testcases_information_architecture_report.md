## 2. 变更详情

### 2.1 G1 — 动态工具栏

**变更**: 移除原顶部 6 个并排按钮，替换为上下文感知操作栏。

- **默认状态**: 仅显示「导入/生成用例」主按钮
- **选择后**: 在 Tab 区下方显示蓝底操作栏
  - 纯 API 选择 → 显示「批量执行」「性能测试」
  - 纯 Web UI 选择 → 显示「Web UI 批量执行」
  - 混合类型 → 黄色警告 ⚠ 仅可导出/删除/评审
  - 通用操作（AI评审、导出、删除）始终可用
  - 末尾「清除选择」按钮

**核心实现**: `selectedCaseAnalysis` useMemo → 分析选中用例类型集合 → 条件渲染按钮。

### 2.2 G2 — 弹窗 Tab case_type 标注

每个导入 Tab 增加输出类型标签：

| Tab | 标签 |
|-----|------|
| 需求文档 | `→ 功能用例`（绿色） |
| Swagger 文件 | `API 接口用例`（蓝色） |
| Swagger URL | `API 接口用例`（蓝色） |
| YApi | `API 接口用例`（蓝色） |
| 手动创建 | 用户自选（功能/API/Web UI） |

### 2.3 G3 — Web UI 表单分区

Web UI 手动创建表单增加三组分隔线标题：

1. **执行配置** — 登录会话管理、浏览器、Headless、Base URL
2. **步骤与断言** — 操作步骤编辑器、断言管理
3. **高级能力** — 页面扫描器、快速测试、快捷模板

每组使用居中文字 + 两侧分割线样式 (`─ 标题 ─`)。

### 2.4 G4 — 页面扫描器折叠

- 用 `<details>` + `<summary>` 替代原始 `<div>`
- 默认折叠（`scannerExpanded` state = false）
- 标题行：▶/▼ 图标 + 「页面扫描器」 + 黄色 `实验功能` 标签
- 展开后内容含 URL 输入、扫描按钮、AI 生成、元素列表

### 2.5 G5 — Tab 动态指标卡片

| Tab | 指标 |
|-----|------|
| 全部 | 总用例、接口用例、功能用例、Web UI、最近失败（5列） |
| 接口测试 | 保留原 API 覆盖率摘要 |
| Web UI | 总数、已执行、通过率、Trace 数、视觉断言（5列） |
| 功能测试 | 总数、已评审、高风险(P0)、待完善（4列） |

**核心实现**: `tabMetrics` useMemo → 按 `sourceFilter` 条件渲染不同指标面板。

### 2.6 G6 — PetStore 提示优化

- 显示当前环境名称（加粗）
- 措辞改为「非 PetStore Demo，已隐藏 N 条示例用例，避免误执行」
- 新增「查看隐藏用例 / 恢复隐藏」切换按钮
- `showHiddenPetStore` state 控制 `filteredTestCases` 过滤逻辑

### 2.7 G7 — 标题升级

- 副标题: `管理和生成测试用例` → `测试用例资产中心 — 统一管理功能、API、Web UI 用例`
