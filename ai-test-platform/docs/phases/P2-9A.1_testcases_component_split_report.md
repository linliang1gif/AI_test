## 架构原则遵守

- **状态不下沉**: 所有 `useState` 保留在 `TestCases.jsx`，子组件通过 props 接收数据和回调
- **无新状态管理库**: 未引入 Redux / Zustand / Context
- **无 API 调用变更**: 子组件不发起网络请求
- **无样式重构**: 保留原有 Tailwind 类名
- **无业务逻辑变更**: 纯展示型拆分
