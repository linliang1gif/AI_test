## 4. Trace 敏感信息风险

### 4.1 风险说明

Playwright trace.zip 内部包含：
- 页面 DOM 快照
- 页面截图（含可能的业务数据）
- 网络请求/响应（含 Cookie、Authorization headers）
- Console 日志
- localStorage/sessionStorage 状态

**Trace 文件本身可能包含页面快照和调试信息，已作为敏感 artifact 管理。**

### 4.2 当前防护措施

| 措施 | 状态 |
|------|------|
| Trace 内容不写入数据库，仅保存路径 | ✅ |
| 日志中不打印 trace 内容 | ✅ |
| Console/Network 日志经过 `sanitize.py` 脱敏后写入 DB | ✅ |
| 前端 Trace 下载处显示警告："Trace 可能包含页面截图和调试信息，请勿外传" | ✅ |
| Real 模式下批量执行前弹出风险提示 | ✅ |
| Trace.zip 内部内容无法清洗（Playwright 原生格式） | ⚠️ MVP 限制 |

### 4.3 前端敏感提示

- **TestCases.jsx**: 批量执行结果对话框显示 amber 警告框
- **TestRunDetailV2.jsx**: Trace 下载链接下方显示 amber 警告文字
- **TestCases.jsx**: real 模式执行前 confirm 对话框包含敏感数据风险提示
