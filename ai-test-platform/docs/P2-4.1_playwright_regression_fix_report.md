- **与默认禁用有关**: 是
- **run_regression_all 注入 TESTING**: 注入到子进程 env，后端独立进程不受影响
- **real 模式拦截**: 仍然有效
- **allow_unsafe_methods**: 仍然有效

## 6. optional=true 是否支持 skipped

**是。** 只有 `optional: true` 的 step 才允许 skipped:

```json
{"action":"click","target":".close-ad","optional":true,"description":"关闭广告弹窗"}
```

实现: `_fail_or_skip()` 函数根据 optional 决定状态。

## 7. skipped 是否单独统计

**是。** `PlaywrightResult.skipped_count` 字段记录跳过数。写入:
- `test_runs.summary` JSON 含 `skipped_count`
- `response_snapshot` 含 `skipped_count`
