## 三、修复方式

### 3.1 `scripts/run_regression_all.py` — 后端生命周期管理

**问题**：回归 runner 只等待后端，不管理后端环境。外部手动启动的后端无法保证 `TESTING=true`。

**修复**：
- 新增 `start_managed_backend()` / `stop_managed_backend()` 函数
- 回归 runner 自动启动后端进程，注入 `TESTING=true` + `TESTING_KEY`
- 自动检测并关闭已有后端进程，避免端口冲突
- 回归结束后自动关闭后端进程
- 默认 `TESTING_KEY = "regression-test-key-auto"`
- 可通过 `REGRESSION_MANAGE_BACKEND=false` 禁用

**首次提交后发现的管道阻塞问题**：
- 初始实现使用 `stdout=subprocess.PIPE`，未读取管道内容
- Windows 管道缓冲区（~64KB）填满后后端进程阻塞，导致后续测试全部超时
- **修复**：改为 `stdout=open("data/regression_backend.log", "w")`，日志写文件

### 3.2 `scripts/test_p2_9b_web_ui_stability.py` — v1 端点修复

```python
# 修复前（404）
requests.get(f"{BASE}/api/test-cases")
requests.get(f"{BASE}/api/projects")

# 修复后
requests.get(f"{BASE}/api/v2/test-cases", params={"limit": 1})
requests.get(f"{BASE}/api/v2/projects")
```

### 3.3 `routes/test_suite_routes.py` — trace_id 缺失修复

测试集执行创建 `TestRun` 时未设置 `trace_id`，导致 `TestRunResponse` Pydantic 验证失败（`trace_id: str` 非 Optional）。

**修复**：生成 `trace_id = f"SUITE_{suite.id}_{os.urandom(4).hex()}"`

### 3.4 `scripts/test_p2_10_test_suite_management.py` — 测试脚本修复 + 覆盖补充

- **修复 `ensure_test_case`**：使用 API 返回的 `test_case_id` 而非本地生成的 ID（create 端点忽略传入 id）
- **修复报告端点**：`POST /api/v2/test-runs/{run_id}/report`（非 `/api/v2/reports/generate`）
- **新增 4 个覆盖项**：
  1. APP_MODE 无污染验证
  2. suite_summary 报告持久化验证
  3. functional 用例标记 skipped 验证
  4. 软删除不影响历史 test_run 验证
