```
│                   AI 测试决策系统                     │

│                                                       │
│  ┌────────────────────────────────────────────┐     │
│  │  🤖 Test Agent (决策层)                    │     │

│  │                                             │     │
│  │  输出: action, modules, priority, confidence│     │
│  └────────────────────────────────────────────┘     │
│                      ↓                               │
│  ┌────────────────────────────────────────────┐     │
│  │  📋 Strategy Engine (策略层)               │     │

│  │  - 生成执行建议                            │     │
│  │                                             │     │
│  │  输出: strategy[], summary, execution_hint  │     │
│  └────────────────────────────────────────────┘     │
│                      ↓                               │
│  ┌────────────────────────────────────────────┐     │
│  │  ⚡ Orchestrator (执行层)                  │     │
│  │  - 智能调度执行                            │     │
│  │  - 并发/串行控制                           │     │
│  │  - 多类型测试支持                          │     │
│  │  - 结果汇总统计                            │     │
│  │                                             │     │
│  │  输出: results[], summary, pass_rate        │     │
│  └────────────────────────────────────────────┘     │
│                                                       │
│  输出: 测试结果 + 统计报告                            │
│                                                       │
└──────────────────────────────────────────────────────┘
```
