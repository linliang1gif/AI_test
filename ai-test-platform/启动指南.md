# 🚀 快速启动指南

## 方式1: 一键启动（最简单）

双击运行:
```
一键启动.bat
```

这会自动启动：
- ✅ 后端服务 (http://127.0.0.1:8081)
- ✅ 前端服务 (http://localhost:3000)

## 方式2: 分步启动

### 步骤1: 检查系统
```
检查系统.bat
```

### 步骤2: 启动后端
```bash
python backend_api_server.py
```

### 步骤3: 启动前端
```bash
cd frontend
npm run dev
```

## 方式3: 使用原有脚本

```bash
python start_platform.py
```

## 📍 访问地址

- **前端界面**: http://localhost:3000
- **后端API**: http://127.0.0.1:8081
- **API文档**: http://127.0.0.1:8081/docs

## 🎯 功能测试

### 1. 上传需求文档
1. 访问前端界面
2. 点击"上传需求文档"
3. 选择.docx或.txt文件
4. 点击"生成测试用例"

### 2. AI生成测试用例
1. 输入需求描述
2. 选择AI提供商（推荐Ollama）
3. 点击"生成"
4. 查看生成的测试用例

### 3. 执行测试
1. 选择测试用例
2. 点击"执行测试"
3. 查看测试结果

### 4. 查看报告
1. 点击"测试报告"
2. 查看详细报告
3. 导出Excel

## ⚠️ 常见问题

### 问题1: 后端启动失败
```bash
# 检查端口占用
netstat -ano | findstr 8081

# 或更换端口
python backend_api_server.py --port 8082
```

### 问题2: 前端启动失败
```bash
# 重新安装依赖
cd frontend
npm install
npm run dev
```

### 问题3: Ollama不可用
```bash
# 启动Ollama
打开Ollama应用

# 或命令行
ollama serve
```

## 🎉 开始使用

1. 双击 `一键启动.bat`
2. 等待服务启动（约10秒）
3. 浏览器访问 http://localhost:3000
4. 开始使用所有功能！
