## 📝 使用步骤

### 1. 确保服务运行

```bash
# 检查后端服务 (端口8000)
# 进程ID: 16

# 检查前端服务 (端口5174)
# 进程ID: 13
```

### 2. 打开测试用例页面

1. 访问: `http://localhost:5174`
2. 点击左侧菜单 "📝 测试用例"

### 3. 上传需求文档

1. 点击右上角 "📄 导入需求文档" 按钮
2. 在弹出的对话框中点击 "选择需求文档"
3. 选择文档文件 (支持格式: .docx, .xlsx, .pdf, .txt, .doc, .xls)
4. 点击 "🚀 开始生成"

### 4. 等待AI生成

- 系统会显示 "AI生成中..." 状态
- AI会自动执行以下步骤:
  - 解析需求文档内容
  - 拆分功能模块
  - 生成测试点和场景
  - 生成完整测试用例
  - 自动去重和质量评估

### 5. 查看生成结果

- 生成完成后会显示成功提示
- 新生成的测试用例会出现在列表顶部
- 可以点击 "查看详情" 查看完整信息

## 🔧 故障排查

### 问题1: 404错误

**症状**: 点击生成按钮后提示404错误

**原因**: 
- 后端服务未启动
- 浏览器缓存旧错误

**解决方案**:
1. 确认后端服务运行: `http://localhost:8000/health`
2. 刷新浏览器页面 (Ctrl+F5 强制刷新)
3. 清除浏览器缓存

### 问题2: 文件上传失败

**症状**: 上传文件后无响应或报错

**原因**:
- 文件格式不支持
- 文件过大
- 网络问题

**解决方案**:
1. 检查文件格式是否在支持列表中
2. 尝试较小的文件
3. 检查网络连接

### 问题3: 生成的测试用例为空

**症状**: 提示成功但没有生成测试用例

**原因**:
- 文档内容无法解析
- AI服务异常

**解决方案**:
1. 检查文档内容是否清晰
2. 查看后端日志
3. 重试生成
