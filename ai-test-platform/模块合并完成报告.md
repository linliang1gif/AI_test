### 3. 使用方式

#### 快速决策模式 (原AI测试决策功能)
```
1. 打开 AI测试控制台
2. 选择执行模式: "仅决策分析 (快速)"
3. 输入需求描述
4. 点击 "⚡ 快速决策"
5. 2-5秒获得决策结果
```

**适用场景**:
- ✅ 代码提交前快速检查
- ✅ 判断是否需要测试
- ✅ 评估风险和优先级
- ✅ 不需要实际执行测试

#### 完整流程模式 (原AI测试控制台功能)
```
1. 打开 AI测试控制台
2. 选择执行模式: "完整流程 (5阶段)"
3. 输入需求描述
4. 选择优先级 (P0/P1/P2)
5. 点击 "🚀 Run AI Test"
6. 10-20秒完成完整测试
```

**适用场景**:
- ✅ 完整的测试验证
- ✅ 需要测试执行结果
- ✅ 需要自动修复
- ✅ 需要完整报告


### API调用逻辑
```javascript
if (executionMode === 'decision-only') {
  // 调用Agent API
  const response = await fetch('/api/agent/analyze', {...})
} else {
  // 调用Pipeline API
  const response = await fetch('/api/pipeline/run', {...})
}
```

### UI动态渲染
```javascript

  <div>优先级选择器</div>

)}
```
