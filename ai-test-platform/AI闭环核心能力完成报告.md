## 🏗️ 三大核心模块

### 模块1: 自动入库 📝

**功能**: 测试执行后自动写入知识库

#### 1.1 Bug自动入库
```python
km.record_test_failure(test_case, error_info)
```

**自动完成**:
- ✅ 生成唯一Bug ID
- ✅ 分析根因(简单版)
- ✅ 判断严重程度
- ✅ 写入SQLite(结构化)
- ✅ 写入ChromaDB(向量化)

**数据流**:
```
测试失败 
  ↓
提取错误信息
  ↓
分析根因
  ↓
SQLite存储(精确查询)
  ↓
ChromaDB存储(语义检索)
```

#### 1.2 测试用例自动入库
```python
km.record_test_case(test_case)
```

**自动完成**:
- ✅ 存储用例详情
- ✅ 记录步骤和期望结果
- ✅ 向量化用例描述
- ✅ 支持来源追溯

#### 1.3 修复模式学习
```python
km.record_healing_success(bug_id, fix_pattern, error_pattern)
```

**自动完成**:
- ✅ 更新Bug为已修复
- ✅ 提取修复模式
- ✅ 记录成功次数
- ✅ 向量化错误模式

### 模块2: 智能检索 🔍

**功能**: 失败时自动查询相似案例

#### 2.1 相似Bug检索
```python
similar_bugs = km.find_similar_bugs(error_message, top_k=5)
```

**双重检索策略**:
1. **ChromaDB语义检索** (主要)
   - 理解错误语义
   - 找到相似问题
   - 返回相似度分数

2. **SQLite关键词检索** (补充)
   - 精确匹配
   - 关键词提取
   - 快速查询

**返回信息**:
- Bug ID
- 根因分析
- 修复建议
- 修复成功率
- 相似度分数

#### 2.2 修复模式检索
```python
patterns = km.find_healing_patterns(error_pattern, top_k=3)
```

**智能推荐**:
- ✅ 查找历史修复模式
- ✅ 按成功率排序
- ✅ 返回修复代码
- ✅ 显示使用次数

#### 2.3 测试用例推荐
```python
cases = km.find_similar_testcases(requirement, top_k=5)
```

**应用场景**:
- 创建新用例时推荐相似用例
- 避免重复设计
- 复用优质用例

## 💡 使用示例

### 场景1: 测试失败自动处理

```python
from knowledge.knowledge_manager import get_knowledge_manager

km = get_knowledge_manager()

# 测试失败时
test_case = {...}
error_info = {...}

# 1. 自动入库
bug_id = km.record_test_failure(test_case, error_info)

# 2. 查找相似Bug
similar_bugs = km.find_similar_bugs(error_info['error_message'])

# 3. 获取修复建议
for bug in similar_bugs:
    if bug['fix_suggestion']:
        print(f"建议: {bug['fix_suggestion']}")
        print(f"成功率: {bug['fix_success']}")

# 4. 查找修复模式
patterns = km.find_healing_patterns(error_info['error_message'])

# 5. 应用修复
for pattern in patterns:
    apply_fix(pattern['fix_pattern'])
    
    # 6. 反馈结果
    if fix_success:
        km.evaluate_healing_result(pattern['pattern_id'], True)
```

### 场景2: 测试用例推荐

```python
# 创建新用例时
requirement = "用户注册功能"

# 查找相似用例
similar_cases = km.find_similar_testcases(requirement)

# 参考历史用例
for case in similar_cases:
    print(f"参考: {case['title']}")
    print(f"步骤: {case['steps']}")
```
