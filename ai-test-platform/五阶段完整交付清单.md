## 🚀 部署说明

### 环境要求

- Python 3.8+
- Node.js 16+
- Ollama（可选）

### 安装步骤

```bash
# 1. 安装Python依赖
pip install -r requirements.txt

# 2. 安装前端依赖
cd frontend
npm install

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 配置AI提供商

# 4. 启动后端
python backend_api_server.py

# 5. 启动前端
cd frontend
npm run dev
```
