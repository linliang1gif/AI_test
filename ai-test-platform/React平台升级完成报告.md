## 🚀 启动方式

### 快速启动
```bash
# 使用智能启动器
python start_react_platform.py

# 选择启动模式:
# 1. 完整平台 (推荐)
# 2. 仅后端API
# 3. 仅前端React
```

### 手动启动
```bash
# 终端1: 启动后端
python backend_api_server.py

# 终端2: 启动前端
cd frontend
npm run dev
```
