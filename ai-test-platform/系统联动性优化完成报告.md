## 🔄 完整的工作流程

### 流程1: 从需求文档生成测试用例

```
1. 创建项目
   POST /api/projects
   → 获得 project_id

2. 上传需求文档
   POST /api/testcases/generate
   参数: file, project_id
   → AI生成测试用例
   → 自动关联到项目

3. 查看项目的测试用例
   GET /api/test-cases?project_id=1
   → 只显示该项目的用例
```

### 流程2: 从API文档生成测试用例

```
1. 创建项目
   POST /api/projects
   → 获得 project_id

2. 导入Swagger文档
   POST /api/swagger/upload
   → 解析所有API接口

3. 从API生成测试用例
   POST /api/apis/{api_id}/generate-testcases
   参数: project_id
   → 自动生成3种测试场景
   → 关联到项目和API

4. 查看API的测试用例
   GET /api/test-cases?project_id=1
   → 筛选出该API的用例
```

### 流程3: 混合使用

```
1. 创建项目
2. 导入Swagger (获得API列表)
3. 上传需求文档 (AI生成功能测试用例)
4. 从API生成接口测试用例
5. 手动补充边界测试用例
6. 执行测试
7. 生成报告
```

## 🚀 使用示例

### 示例1: 快速开始

```bash
# 1. 创建项目
curl -X POST http://localhost:8081/api/projects \
  -H "Content-Type: application/json" \
  -d '{
    "name": "电商系统",
    "description": "电商平台测试",
    "environment": "staging",
    "baseUrl": "http://api.example.com"
  }'
# 返回: {"project": {"id": 1, ...}}

# 2. 上传需求文档生成测试用例
curl -X POST http://localhost:8081/api/testcases/generate?project_id=1 \
  -F "file=@requirements.docx"
# 返回: {"success": true, "count": 5, "testCases": [...]}

# 3. 查看项目的测试用例
curl http://localhost:8081/api/test-cases?project_id=1
# 返回: {"testCases": [...], "project_id": 1}
```

### 示例2: API测试

```bash
# 1. 导入Swagger文档
curl -X POST http://localhost:8081/api/swagger/upload \
  -F "file=@swagger.json"
# 返回: {"success": true, "count": 20, "apis": [...]}

# 2. 从API生成测试用例
curl -X POST http://localhost:8081/api/apis/1/generate-testcases?project_id=1
# 返回: {"success": true, "count": 3, "testCases": [...]}
```
