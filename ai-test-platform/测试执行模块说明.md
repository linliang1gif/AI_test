# 测试执行模块 - 数据来源和执行说明

## 📊 数据来源

### 1. 点击"运行新测试"按钮时

**前端操作** (TestRuns.jsx):
```javascript
const handleRunNew = () => {
  testRunsAPI.start({ environment: 'staging' })
    .then(data => {
      const newRun = data.testRun
      setTestRuns(prev => [newRun, ...prev])
      setSelectedRun(newRun)
      loadTestRuns()
    })
}
```

**后端处理** (backend_api_server.py):
```python
@self.app.post("/api/test-runs")
async def start_test_run(background_tasks, request):
    # 1. 获取要执行的测试用例
    if test_case_ids:
        # 如果指定了测试用例ID,使用指定的用例
        test_cases_to_run = [tc for tc in self.test_cases if tc["id"] in test_case_ids]
    elif project_id:
        # 如果指定了项目ID,使用该项目的所有用例
        test_cases_to_run = [tc for tc in self.test_cases if tc.get("project_id") == project_id]
    else:
        # 默认:使用所有测试用例
        test_cases_to_run = self.test_cases
    
    # 2. 创建测试运行记录
    new_run = {
        "id": run_id,
        "name": f"测试运行 #{run_id}",
        "status": "running",
        "totalTests": len(test_cases_to_run),
        ...
    }
    
    # 3. 在后台执行测试
    background_tasks.add_task(self._execute_test_run, task_id, run_id, test_cases_to_run)
```

## 🎯 执行的是什么

### 当前实现:执行测试用例模块的用例

**数据来源**: `self.test_cases` (测试用例模块)

这些测试用例来自:
1. **AI生成**: 在测试用例模块上传需求文档生成的用例
2. **API生成**: 从API Explorer导入Swagger文档生成的用例
3. **手动创建**: 用户手动添加的测试用例

**执行逻辑** (_execute_test_run方法):
```python
async def _execute_test_run(self, task_id, run_id, test_cases, resume=False):
    # 遍历每个测试用例
    for i in range(start_index, total_tests):
        test_case = test_cases[i]
        
        # 1. 记录日志
        run["logs"].append({
            "time": datetime.now().strftime("%H:%M:%S"),
            "level": "INFO",
            "message": f"执行测试用例: {test_case['title']}"
        })
        
        # 2. 模拟测试执行(当前是模拟,可以改为真实执行)
        await asyncio.sleep(2)
        
        # 3. 随机决定测试结果(80%通过率)
        test_passed = random.random() < 0.8
        
        # 4. 更新进度和结果
        run.update({
            "progress": progress,

        })
```

## 🔄 完整执行流程

```
用户点击"运行新测试"
    ↓
前端发送 POST /api/test-runs
    ↓
后端获取测试用例数据源
    ├─ 默认: self.test_cases (所有测试用例)
    ├─ 按项目: 筛选指定项目的用例
    └─ 按ID: 筛选指定ID的用例
    ↓
创建测试运行记录
    ↓
后台任务开始执行
    ├─ 遍历每个测试用例
    ├─ 记录执行日志
    ├─ 模拟/真实执行测试
    ├─ 更新进度和结果
    └─ 保存到数据库
    ↓
前端轮询获取状态
    ├─ 每2秒查询一次
    ├─ 更新进度条
    ├─ 显示实时日志
    └─ 显示测试结果
```

## 🎨 如何指定要执行的测试

### 方式1: 执行所有测试用例(当前默认)
```javascript
// 前端
testRunsAPI.start({ environment: 'staging' })

// 后端会执行 self.test_cases 中的所有用例
```

### 方式2: 执行指定项目的测试用例
```javascript
// 前端
testRunsAPI.start({ 
  environment: 'staging',
  project_id: 1  // 指定项目ID
})

// 后端会执行该项目的所有用例
```

### 方式3: 执行指定的测试用例
```javascript
// 前端
testRunsAPI.start({ 
  environment: 'staging',
  test_case_ids: [1, 2, 3]  // 指定用例ID
})

// 后端只执行这些指定的用例
```

## 🔧 当前执行方式

### 模拟执行(当前实现)
```python
# 模拟测试执行
await asyncio.sleep(2)  # 模拟执行时间

# 随机决定测试结果
test_passed = random.random() < 0.8
```

**特点**:
- 不需要真实的测试环境
- 快速演示功能
- 80%通过率模拟

### 真实执行(可扩展)
可以改为调用真实的测试执行器:
```python
# 方式1: 调用pytest执行器
from executor.pytest_runner import PytestRunner
runner = PytestRunner()
result = runner.run_test_case(test_case)

# 方式2: 调用API测试
import requests
response = requests.post(test_case['api_url'], ...)
test_passed = response.status_code == 200

# 方式3: 调用自动化脚本
script_path = f"output/scripts/{test_case['script_name']}"
result = subprocess.run(['pytest', script_path], ...)
```

async def _execute_test_run(self, task_id, run_id, test_cases, resume=False):
