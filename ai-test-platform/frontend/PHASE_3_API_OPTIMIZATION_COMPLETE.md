| 功能 | 旧版 | 新版 |

## 🚀 使用指南

### 1. 访问新版页面

```
http://localhost:5173/api-explorer
```

旧版页面（备份）：
```
http://localhost:5173/api-explorer-old
```

### 2. 导入Swagger

**URL导入**:
1. 点击"导入Swagger"
2. 选择"URL导入"
3. 输入Swagger URL
4. 点击"开始解析"

**文件上传**:
1. 点击"导入Swagger"
2. 选择"文件上传"
3. 拖拽或选择文件
4. 自动开始解析

### 3. 筛选API

1. 选择HTTP方法
2. 输入标签关键词
3. 输入路径关键词
4. 实时查看结果

### 4. 操作API

- **查看**: 跳转到API详情页
- **测试**: 打开API执行器
- **数据**: 生成测试数据
- **复制**: 复制API信息到剪贴板
