## 🚀 使用指南

### 1. 访问新版页面

```
http://localhost:5173/projects
```

旧版页面（备份）：
```
http://localhost:5173/projects-old
```

### 2. 创建项目

1. 点击"创建项目"按钮
2. 填写项目信息：
   - 项目名称（必填）
   - 项目描述
   - 环境（开发/测试/生产）
   - 基础URL（必填）
3. 点击"创建项目"

### 3. 筛选项目

1. 选择环境类型
2. 选择状态
3. 输入负责人名称
4. 实时查看结果

### 4. 批量操作

1. 勾选多个项目
2. 点击"批量运行"或"批量删除"
3. 确认操作

### 5. 查看项目详情

- 点击项目名称
- 或点击"查看详情"按钮
