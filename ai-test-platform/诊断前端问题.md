# 前端数据显示问题诊断指南

## 当前状态
✅ 后端API服务器运行正常 (端口 8081)
✅ 前端开发服务器运行正常 (端口 3000)
✅ Vite代理配置正确 (指向 8081)
✅ API端点返回数据正常

## 诊断步骤

### 1. 打开浏览器开发者工具
1. 访问 http://localhost:3000
2. 按 F12 打开开发者工具
3. 切换到 "Console" (控制台) 标签

### 2. 检查控制台错误
查看是否有以下类型的错误：
- ❌ 网络请求失败 (Network errors)
- ❌ JavaScript 错误 (Uncaught errors)
- ❌ CORS 错误 (跨域错误)
- ❌ 组件渲染错误

### 3. 检查网络请求
1. 切换到 "Network" (网络) 标签
2. 刷新页面 (F5)
3. 查看是否有以下请求：
   - `/api/dashboard/stats`
   - `/api/projects`
   - `/api/test-cases`
   - `/api/apis`
   
4. 点击每个请求，查看：
   - Status: 应该是 200
   - Response: 应该有 JSON 数据

### 4. 使用测试页面
访问: http://localhost:3000/test_api_connection.html

这个页面会自动测试所有API端点并显示结果。

### 5. 常见问题和解决方案

#### 问题1: 页面显示"加载中..."但一直不变
**原因**: API请求可能被阻塞或超时
**解决**: 
- 检查浏览器控制台的Network标签
- 确认后端服务器正在运行
- 检查防火墙设置

#### 问题2: 显示"加载失败"错误
**原因**: API请求返回错误
**解决**:
- 查看控制台的具体错误信息
- 检查后端日志
- 确认API端点路径正确

#### 问题3: 页面空白，没有任何内容
**原因**: React组件渲染失败
**解决**:
- 检查控制台是否有JavaScript错误
- 查看是否有组件导入错误
- 确认所有依赖已安装

#### 问题4: 数据显示为 undefined 或 null
**原因**: API响应格式不匹配
**解决**:
- 检查API返回的数据结构
- 确认前端代码正确解析响应

\`\`\`powershell
# 检查端口占用
netstat -ano | findstr "3000"
netstat -ano | findstr "8081"
\`\`\`

## 下一步操作

如果以上步骤都正常，但页面仍然没有数据：

1. **清除浏览器缓存**
   - Ctrl + Shift + Delete
   - 选择"缓存的图片和文件"
   - 点击"清除数据"

2. **硬刷新页面**
   - Ctrl + F5 (Windows)
   - 或 Ctrl + Shift + R

3. **重启前端服务**
   - 停止当前的 npm run dev
   - 重新运行 npm run dev

4. **检查浏览器兼容性**
   - 尝试使用 Chrome 或 Edge 浏览器
   - 确保浏览器版本较新
