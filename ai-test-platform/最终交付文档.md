## 🚀 部署说明

### 系统要求
- Python 3.8+
- Node.js 16+
- 8GB RAM
- 10GB 磁盘空间

### 安装步骤

#### 1. 后端安装
```bash
cd ai测试/ai-test-platform

# 安装Python依赖
pip install -r requirements.txt

# 启动后端服务器
py backend_api_server.py
```

#### 2. 前端安装
```bash
cd ai测试/ai-test-platform/frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

#### 3. 访问系统
- 前端: http://localhost:5174
- 后端: http://localhost:8000
- API文档: http://localhost:8000/docs
