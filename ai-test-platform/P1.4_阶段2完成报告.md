## 📝 使用指南

### 快速开始 - Test Cases集成

1. **绑定数据集到测试用例**
   ```
   1. 打开 http://localhost:5174/test-cases
   2. 找到要绑定数据集的测试用例
   3. 点击右侧的"🏭 数据集"按钮
   4. 在弹出的对话框中选择数据集
   5. 点击"绑定数据集"
   6. 绑定成功后按钮显示"已绑定"
   ```

2. **执行使用数据集的测试用例**
   ```
   1. 测试用例已绑定数据集
   2. 执行测试时自动加载数据集
   3. 使用数据集中的数据进行测试
   4. 测试结果包含数据集信息
   ```

### 快速开始 - Automation集成

1. **生成包含数据集的脚本**
   ```
   1. 打开 http://localhost:5174/automation
   2. 在右侧"生成设置"中配置框架和语言
   3. 在"选择测试数据集"下拉框中选择数据集
   4. 点击"生成新脚本"
   5. 等待3-5秒后刷新页面
   6. 查看生成的脚本,包含数据生成代码
   ```

2. **生成的脚本示例**
   ```python
   import pytest
   import requests
   from test_data import factory
   
   class TestAPI:
       def setup_method(self):
           # 从数据集加载数据
           self.test_data = factory.load_dataset("dataset_id")
       
       def test_api_call(self):
           # 使用数据集中的数据
           response = requests.post(
               self.test_data['api_endpoint'],
               json=self.test_data['payload']
           )
           assert response.status_code == 200
   ```

### 快速开始 - Reports

1. **生成测试报告**
   ```
   1. 打开 http://localhost:5174/reports
   2. 点击"生成报告"按钮
   3. 选择一个已完成的测试运行
   4. 点击"生成报告"
   5. 等待生成完成
   6. 在报告列表中查看新报告
   ```

2. **查看和下载报告**
   ```
   1. 在报告列表中找到报告
   2. 点击"查看"按钮在新窗口打开
   3. 点击"下载"按钮下载HTML文件
   4. 报告包含图表和详细信息
   ```
