## 🚀 使用指南

### 快速开始

1. **访问前端**
   ```
   http://localhost:3000
   ```

2. **创建项目**
   - 进入"项目管理"
   - 点击"创建项目"
   - 填写项目信息

3. **生成测试用例**
   
   **方式1: 从需求文档生成**
   - 进入"测试用例"
   - 上传需求文档
   - AI自动生成测试用例
   
   **方式2: 从API生成**
   - 进入"API Explorer"
   - 导入Swagger文档
   - 选择API生成测试用例

4. **执行测试**
   - 进入"测试运行"
   - 点击"运行新测试"
   - 查看实时执行进度和日志
   - **现在会真实执行API测试!**

## 🔧 配置说明

### 测试环境配置

创建 `test_config.json`:
```json
{
  "test_environments": {
    "development": {
      "base_url": "http://localhost:8080",
      "timeout": 10
    },
    "staging": {
      "base_url": "http://staging.example.com",
      "timeout": 15
    }
  }
}
```
