## 📝 测试AI生成功能

### 方法1: 使用示例需求文档

1. 点击左侧菜单 **"测试用例"**
2. 点击 **"上传需求文档"** 按钮
3. 选择文件: `G:\ai测试\ai-test-platform\data\requirement.txt`
4. 等待10-30秒
5. 查看生成的测试用例

创建一个需求文档（.txt或.md格式），内容示例:

```markdown
- 个人信息管理
- 收货地址管理

## 商品管理

- 商品详情查看
- 购物车管理

## 订单管理
- 订单创建和支付
- 订单查询和取消
- 订单状态跟踪
```

然后上传这个文档。

## 🐛 遇到问题？

### 问题1: 后端启动失败
```bash
# 检查端口是否被占用
netstat -ano | findstr :8081

# 如果被占用，修改backend_api_server.py中的端口号
```

### 问题2: 前端无法访问
```bash
# 检查Node.js版本
node --version  # 应该 >= 16.0.0

# 重新安装依赖
cd frontend
npm install
```

### 问题3: AI生成失败
```bash
# 运行测试脚本诊断
py test_deepseek_api.py
```
