## 🗄️ SQLite数据库表结构

### 已创建的表

1. **bug_records** - Bug记录表
   ```sql
   - bug_id: Bug唯一标识
   - bug_type: Bug类型
   - severity: 严重程度
   - root_cause: 根本原因
   - fix_suggestion: 修复建议
   - fix_success: 修复成功标志
   - error_log: 错误日志
   - timestamp: 时间戳
   ```

2. **healing_records** - 自修复模式记录表
   ```sql
   - pattern_id: 模式唯一标识
   - error_pattern: 错误模式
   - fix_pattern: 修复模式
   - success_count: 成功次数
   - fail_count: 失败次数
   - last_used: 最后使用时间
   ```

3. **testcase_records** - 测试用例记录表
   ```sql
   - tc_id: 测试用例ID
   - title: 标题
   - module: 模块
   - priority: 优先级
   - steps_json: 测试步骤(JSON)
   - expected: 预期结果
   - source: 来源
   - quality_score: 质量评分
   - created_at: 创建时间
   ```

4. **requirement_records** - 需求记录表
   ```sql
   - req_id: 需求ID
   - content: 需求内容
   - module: 模块
   - source_file: 源文件
   - created_at: 创建时间
   ```

5. **business_rule_records** - 业务规则记录表
   ```sql
   - rule_id: 规则ID
   - rule_text: 规则文本
   - module: 模块
   - source_req_id: 源需求ID
   - created_at: 创建时间
   ```

6. **req_api_mapping** - 需求-API映射表
   ```sql
   - id: 自增ID
   - req_id: 需求ID
   - api_path: API路径
   - api_method: API方法
   - confidence: 置信度
   - created_at: 创建时间
   ```
