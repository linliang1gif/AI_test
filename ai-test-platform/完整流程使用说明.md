# 测试用例完整流程使用说明

## 🎯 功能概述

从需求文档上传到测试执行的完整自动化流程已打通，支持：
- ✅ AI生成测试用例
- ✅ 自动化脚本生成
- ✅ 一键执行测试
- ✅ 查看执行结果

---

## 📖 使用步骤

### 1. 生成测试用例

1. 打开前端页面: http://localhost:5173
2. 进入"测试用例"页面
3. 点击"上传需求文档"按钮
4. 选择Word/PDF/TXT文件
5. 等待AI生成测试用例
6. 查看生成的测试用例列表

### 2. 生成自动化脚本

1. 在测试用例列表中找到目标用例
2. 点击操作列的"生成脚本"按钮(紫色)
3. 等待脚本生成完成
4. 在弹出的对话框中查看生成的pytest脚本
5. (可选)点击"下载脚本"保存到本地

### 3. 执行测试

1. 在测试用例列表中找到目标用例
2. 点击操作列的"执行"按钮(绿色)
3. 确认执行
4. 等待执行完成
5. 查看执行结果对话框:
   - 执行状态(passed/failed)
   - 执行耗时
   - 断言结果(通过/失败数量)
   - 详细日志

### 4. 查看执行历史

1. 进入"测试执行"页面
2. 查看所有测试执行记录
3. 按时间倒序排列
4. 点击查看详细日志

---

## 🔧 执行模式

系统支持4种测试执行模式:

### 1. 模拟执行(默认)
- 适用于: 所有测试用例
- 特点: 快速、稳定、90%通过率
- 用途: 演示、开发、验证流程

### 2. API测试执行
- 适用于: source='api_generated'的测试用例
- 特点: 发送真实HTTP请求
- 用途: API接口测试

### 3. 脚本执行
- 适用于: 有script_path的测试用例
- 特点: 使用pytest执行脚本
- 用途: 自动化回归测试

### 4. 智能执行
- 适用于: source='ai_generated'的测试用例
- 特点: AI分析后选择执行方式
- 用途: 复杂场景测试

---

## 📊 执行结果说明

### 状态类型
- `passed` - 测试通过 ✅
- `failed` - 测试失败 ❌
- `skipped` - 测试跳过 ⏭️
- `pending` - 待执行 ⏳

### 断言结果
```json
{
  "total": 5,      // 总断言数
  "passed": 5,     // 通过数
  "failed": 0      // 失败数
}
```

### 响应时间
- < 500ms: 快速 🚀
- 500ms - 2s: 正常 ⏱️
- > 2s: 较慢 🐌

## 💡 使用技巧

### 批量操作
1. 勾选多个测试用例
2. 点击"批量删除"按钮
3. 确认删除

### 数据绑定
1. 点击测试用例的"绑定数据"按钮
2. 选择或创建数据集
3. 绑定到测试用例

### 脚本下载
1. 生成脚本后
2. 点击"下载脚本"按钮
3. 保存为.py文件
4. 可在本地使用pytest执行

---

## 📝 注意事项

1. **模拟执行**: 默认使用模拟执行，不会发送真实请求
2. **真实执行**: 需要配置目标系统的API地址
3. **脚本执行**: 需要安装pytest: `pip install pytest`
4. **数据持久化**: 当前使用内存存储，重启后数据会丢失
