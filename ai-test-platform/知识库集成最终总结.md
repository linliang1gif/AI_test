**示例**:

## 🚀 使用方式

### 方式1: 命令行导入

```bash
# 导入Swagger
cd ai测试/ai-test-platform
py import_swagger_to_knowledge.py

# 导入代码库
py import_codebase_to_knowledge.py

# 查看演示
py demo_swagger_knowledge_usage.py
```

### 方式2: AI测试控制台

```bash
# 启动平台
py start_platform.py

# 访问 http://localhost:5174/ai-console
# 输入测试需求,AI自动使用知识库
```

### 方式3: Python API

```python
from knowledge.knowledge_manager import KnowledgeManager

km = KnowledgeManager()

# 查询API
api_collection = km.kb.get_collection("apis")
results = api_collection.query(
    query_texts=["采购订单"],
    n_results=5
)

# 查询代码
code_collection = km.kb.get_collection("backend_code")
results = code_collection.query(
    query_texts=["PurchaseOrderService"],
    n_results=3
)
```

## 🔧 技术实现

### 1. Swagger解析
- 使用 `parser/swagger_parser.py`
- 支持Swagger 2.0格式
- 提取API路径、方法、参数、响应

### 2. 代码索引
- 使用 `import_codebase_to_knowledge.py`
- 支持Java、JavaScript、Vue、XML等
- 提取类名、方法名、包名等元数据

### 3. 向量化存储
- 使用ChromaDB向量数据库
- 支持语义检索和相似度匹配
- 自动生成文档向量

### 4. 知识检索
- 使用 `knowledge/knowledge_manager.py`
- 支持自然语言查询
- 返回相似度排序的结果
