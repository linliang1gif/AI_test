## 📝 使用指南

### 快速开始

1. **启动服务**
   ```bash
   # 前端 (端口3000)
   cd frontend
   npm run dev
   
   # 后端 (端口8081)
   py backend_api_server.py
   ```

2. **访问系统**
   - 前端: http://localhost:3000
   - 后端API: http://127.0.0.1:8081
   - API文档: http://127.0.0.1:8081/docs

3. **基本工作流**
   ```
   创建项目 → 导入API/上传需求 → 生成测试用例 → 运行测试 → 生成报告
   ```

### 核心功能使用

#### 1. 生成测试用例
- **从需求文档**: 上传Word/PDF → AI生成
- **从API文档**: 导入Swagger → 选择API → 生成

#### 2. 执行测试
- 进入"测试运行"
- 点击"运行新测试"
- 选择测试用例
- 查看实时进度和日志

#### 3. 生成报告
- 进入"测试报告"
- 点击"生成报告"
- 选择测试运行
- 查看HTML报告
