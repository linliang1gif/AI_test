## 📋 核心功能使用

### 1. 测试报告生成 (NEW!)

#### 步骤:
1. 访问 http://localhost:3000/reports
2. 点击右上角"生成报告"按钮
3. 在对话框中选择一个已完成的测试运行
4. 点击"生成报告"按钮
5. 等待生成完成
6. 点击"查看"按钮在新窗口打开HTML报告

#### 功能:
- ✅ 从测试运行生成报告
- ✅ 美观的HTML报告
- ✅ 彩色日志显示
- ✅ 统计图表
- ✅ 下载报告
- ✅ 删除报告

### 2. 项目管理

#### 创建项目:
1. 访问 http://localhost:3000/projects
2. 点击"创建项目"
3. 填写项目信息
4. 保存

### 3. 测试用例生成

#### 方式1: 从需求文档
1. 访问 http://localhost:3000/test-cases
2. 点击"上传需求文档"
3. 选择Word/PDF文件
4. AI自动生成测试用例

#### 方式2: 从API文档
1. 访问 http://localhost:3000/api-explorer
2. 选择"文件上传"或"URL导入"
3. 导入Swagger/OpenAPI文档
4. 选择API生成测试用例

### 4. 测试执行

#### 运行测试:
1. 访问 http://localhost:3000/test-runs
2. 点击"运行新测试"
3. 选择项目和测试用例
4. 点击"开始测试"
5. 查看实时进度和日志

#### 特性:
- ✅ 真实API测试执行
- ✅ pytest脚本执行
- ✅ 实时进度显示
- ✅ 详细执行日志
- ✅ 暂停/停止/恢复控制

### 5. 自动化脚本

#### 生成脚本:
1. 访问 http://localhost:3000/automation
2. 点击"生成脚本"
3. 选择测试用例
4. 选择框架(pytest)和语言(Python)
5. 生成并下载脚本

#### 执行脚本:
1. 在脚本列表中找到脚本
2. 点击"运行脚本"
3. 查看执行状态和结果

## 🎯 完整工作流示例

### 场景: 测试一个新的API

```
1. 创建项目
   → 项目管理 → 创建项目 → 填写信息

2. 导入API文档
   → API Explorer → 文件上传 → 选择Swagger文件

3. 生成测试用例
   → 选择API → 点击"生成测试用例"

4. 运行测试
   → 测试运行 → 运行新测试 → 选择用例 → 开始

5. 生成报告
   → 测试报告 → 生成报告 → 选择测试运行 → 查看
```

## 💡 使用技巧

### 1. 测试用例生成
- 需求文档越详细,生成的测试用例越准确
- API文档建议使用Swagger 2.0或OpenAPI 3.0格式

### 2. 测试执行
- API测试需要目标服务器运行
- 可以在测试用例中配置base_url

### 3. 报告生成
- 只能从已完成的测试运行生成报告
- HTML报告可以直接在浏览器中打开
- 使用浏览器的"打印"功能可以保存为PDF

### 4. 自动化脚本
- 生成的pytest脚本可以直接运行
- 脚本保存在 `output/scripts/` 目录

## 🐛 故障排查

### 问题: 前端无法连接后端
**解决**: 
1. 检查后端是否运行: http://127.0.0.1:8081/docs
2. 检查CORS配置
3. 查看浏览器控制台错误

### 问题: AI生成失败
**解决**:
1. 检查Ollama是否运行: http://localhost:11434
2. 检查模型是否下载: `ollama list`
3. 增加超时时间(已设置为180秒)

### 问题: 测试执行失败
**解决**:
1. 检查目标服务器是否运行
2. 检查base_url配置
3. 查看执行日志

### 问题: 报告生成失败
**解决**:
1. 确认测试运行已完成
2. 检查测试运行是否有数据
3. 查看后端日志
