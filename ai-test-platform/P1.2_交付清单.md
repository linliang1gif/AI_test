## 🎯 使用示例

### 快速开始
```python
from test_data.data_factory import factory

# 基础数据
email = factory.email()
phone = factory.phone()

# 业务对象
user = factory.user()
order = factory.order()

# Mock数据
response = factory.api_response(success=True)
token = factory.jwt_token(user_id="123")

# 批量生成
users = factory.batch("user", 10)

# 模板使用
data = factory.from_template("user_login", username="test")

# 依赖管理
order = factory.with_dependencies("order")
```

## 💡 最佳实践

1. **使用模板**: 为常用数据结构创建模板,提高复用性
2. **批量生成**: 需要大量数据时使用batch方法
3. **依赖管理**: 复杂场景使用依赖链,保证数据一致性
4. **边界测试**: 使用boundary_values和invalid_values进行边界测试
5. **自定义覆盖**: 使用overrides参数自定义特定字段
