## 🚀 使用指南

### 启动后端服务器

```bash
cd ai测试/ai-test-platform
py backend_api_server.py
```

服务器信息:
- 🌐 API文档: http://localhost:8000/docs
- 🔍 健康检查: http://localhost:8000/health
- 📡 端口: 8000

### 启动前端服务器

```bash
cd frontend
npm run dev
```

访问地址:
- 🏠 主页: http://localhost:5173
- 🏭 测试数据工厂: http://localhost:5173/test-data-factory

### API调用示例

#### 生成用户数据
```bash
curl -X POST http://localhost:8000/api/test-data/generate \
  -H "Content-Type: application/json" \
  -d '{"data_type": "user", "count": 1}'
```

#### AI智能生成
```bash
curl -X POST http://localhost:8000/api/test-data/smart-generate \
  -H "Content-Type: application/json" \
  -d '{"field_name": "user_email", "context": {"domain": "test.com"}}'
```

#### 获取测试场景
```bash
curl http://localhost:8000/api/test-data/scenarios/user
```
