## 📊 API接口说明

### 生成数据
```bash

{
  "data_type": "user",
  "count": 5,
  "context": {},
  "overrides": {}
}
```

### AI智能生成
```bash
POST /api/test-data/smart-object
{
  "schema": {
    "user_id": "string",

  },
  "context": {

  }

```

```bash

}
```

```bash
GET /api/test-data/stats
```

## 🔧 故障排查

### 问题1: API调用失败
**原因**: 后端未启动或端口不对  
**解决**: 确认后端在8000端口运行

### 问题2: 前端页面空白
**原因**: 路由未配置或组件导入错误  
**解决**: 检查App.jsx配置,查看控制台错误

### 问题3: 数据生成失败
**原因**: test_data模块导入失败  
**解决**: 检查后端日志,确认模块路径

### 问题4: CORS错误
**原因**: 跨域配置问题  
**解决**: 确认backend_api_server.py中CORS配置
