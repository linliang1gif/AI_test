## 🎮 使用流程

### 1. 安装和配置Ollama
```bash
# 1. 安装Ollama
curl -fsSL https://ollama.ai/install.sh | sh

# 2. 启动服务
ollama serve

# 3. 下载模型
ollama pull deepseek-coder
ollama pull qwen2.5
```

### 2. 配置AI测试平台
```env
# .env文件配置
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODELS=deepseek-coder,qwen2.5,llama3
DEFAULT_AI_PROVIDER=ollama
```

### 3. 使用AI提供商管理
1. 启动AI测试平台
2. 进入"AI分析"页面
3. 点击"管理提供商"
4. 查看提供商状态
5. 测试连接
6. 切换提供商
