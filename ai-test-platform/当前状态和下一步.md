## 🛠️ 如果导入遇到问题

### 问题1: 导入时间太长

**解决方案**: 
- 导入可以在后台运行
- 先导入Swagger(快),后导入代码库(慢)
- 或者只导入Swagger,也能看到效果

### 问题2: 导入失败

**检查**:
1. Swagger文件是否存在: `data/swagger/*.json`
2. 代码库路径是否正确: `../后端1.2.1`, `../前端-1.2.1`
3. ChromaDB是否正常: `py check_knowledge_status.py`

**重新导入**:
```bash
# 清空知识库(如果需要)
# 然后重新导入
py import_swagger_to_knowledge.py
```

### 问题3: 想快速测试

**方案**: 即使知识库为空,系统也能工作(使用Fallback)

```bash
# 直接运行测试
py test_complete_rag_integration.py
```

系统会:
- 使用Fallback机制
- 不会中断
- 但效果不如有数据时明显
