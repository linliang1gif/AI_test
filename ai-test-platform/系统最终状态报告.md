## 🎨 技术架构

### 前端架构
```
React 18 + Vite
├── 页面组件 (11个主要页面)
├── 通用组件 (UI组件库)
├── 服务层 (API调用)
└── 状态管理 (React Hooks)
```

### 后端架构
```
FastAPI + Python
├── API服务器 (backend_api_server.py)
├── 数据持久化 (persistence_manager.py)
├── 测试数据工厂 (test_data/)
├── 数据集管理 (dataset_manager.py)
└── AI集成 (ai/)
```

### 数据存储
```
文件系统存储

│   ├── projects.json
│   └── test_runs.json
└── test_data/storage/
    └── datasets.json
```

## 🚀 核心工作流

### 完整测试流程
```
1. 创建项目
   ↓
2. 导入Swagger/需求文档
   ↓
3. AI生成测试用例
   ↓
4. 生成测试数据
   ↓
5. 保存为数据集
   ↓
6. 绑定数据集到测试用例
   ↓
7. 生成自动化脚本
   ↓
8. 执行测试
   ↓
9. 生成测试报告
   ↓
10. AI分析和洞察
```

## 📝 部署说明

### 系统要求
- Python 3.8+
- Node.js 16+
- 8GB RAM
- 10GB 磁盘空间

### 启动步骤
```bash
# 1. 启动后端
cd ai测试/ai-test-platform
py backend_api_server.py

# 2. 启动前端(新终端)
cd frontend
npm run dev

# 3. 访问系统
# 前端: http://localhost:5174
# 后端: http://localhost:8000
# API文档: http://localhost:8000/docs
```
