## 📊 问题总结

### 发现的问题

1. **❌ Config 配置缺少 Anthropic 支持**
   - 缺少 `anthropic_api_key` 和 `anthropic_base_url` 配置
   - 缺少 `get_ai_config_for_provider` 对 anthropic 的支持

2. **❌ LLM Client 缺少 Anthropic 支持**
   - `__init__` 方法中没有 anthropic 分支
   - 导致 base_url 为 None

3. **❌ Anthropic API 配置错误**
   - 配置的 URL 返回 HTML 页面,不是 JSON API
   - 无法正常调用

4. **❌ DeepSeek API Key 无效**
   - 402 Payment Required 错误
   - API Key 过期或余额不足

## ✅ 已完成的修复

### 1. 添加 Anthropic 支持

**修改文件**: `config/config.py`

```python
# 添加 Anthropic 配置字段
@dataclass
class AIConfig:
    anthropic_api_key: str
    anthropic_base_url: str
    # ...

# 添加配置加载
def _load_ai_config(self):
    return AIConfig(
        anthropic_api_key=os.getenv("ANTHROPIC_API_KEY", ""),
        anthropic_base_url=os.getenv("ANTHROPIC_BASE_URL", "https://api.anthropic.com"),
        # ...
    )

# 添加 provider 支持
def get_ai_config_for_provider(self, provider: str = None):
    if provider == "anthropic":
        return {
            "api_key": self.ai.anthropic_api_key,
            "base_url": self.ai.anthropic_base_url,
            # ...
        }
```

**修改文件**: `agent/llm_client.py`

```python
# 添加 Anthropic 初始化
def __init__(self, provider, model):
    if self.provider == 'anthropic':
        self.base_url = self.config.ai.anthropic_base_url
        self.api_key = self.config.ai.anthropic_api_key
```

### 2. 切换到 Mock 模式

**修改文件**: `.env`

```env
DEFAULT_AI_PROVIDER=mock
DEFAULT_AI_MODEL=mock-model
```

**原因**: 
- Anthropic API 配置有问题
- DeepSeek API Key 无效
- Mock 模式可以让系统立即运行起来

## 🎓 学到的经验

### 1. 配置管理很重要
- 所有 AI 提供商都需要在配置中明确支持
- 不能假设代码会自动处理新的 provider

### 2. 错误处理要完善
- API 调用失败时要有降级方案
- 返回的错误信息要清晰明确

### 3. Mock 模式很有用
- 可以快速验证系统功能
- 不依赖外部 API
- 适合开发和测试

### 4. 诊断工具很关键
- 全面的诊断脚本可以快速定位问题
- 清晰的错误信息可以节省大量时间
