# 自动化脚本执行状态显示

## 新增功能

现在点击"运行脚本"按钮后,页面会显示一个**实时执行状态面板**,包含:

### 1. 执行状态面板

位置: 在统计卡片下方,脚本列表上方

显示内容:
- ✅ 脚本名称
- ✅ 执行状态 (运行中/已完成/失败)
- ✅ 进度条 (0-100%)
- ✅ 当前步骤
- ✅ 状态消息
- ✅ 执行结果 (总测试数/通过/失败/耗时)
- ✅ 任务ID

### 2. 状态图标

- 🔄 运行中: 橙色旋转时钟图标
- ✅ 已完成: 绿色对勾图标
- ❌ 失败: 红色警告图标

### 3. 进度条

- 蓝色进度条实时更新
- 显示百分比 (0-100%)
- 平滑过渡动画

### 4. 执行结果卡片

完成后显示:
```
┌─────────────────────────┐
│ 执行结果                │
├─────────────────────────┤
│ 总测试数: 5             │
│ 通过: 4 ✅              │
│ 失败: 1 ❌              │
│ 耗时: 5.23s             │
└─────────────────────────┘
```

## 技术实现

### 前端状态管理
```javascript
const [executionStatus, setExecutionStatus] = useState(null)
const [taskId, setTaskId] = useState(null)
```

### 轮询机制
```javascript
const pollTaskStatus = (taskId) => {
  const checkStatus = () => {
    fetch(`/api/tasks/${taskId}/status`)
      .then(r => r.json())
      .then(data => {
        setExecutionStatus({
          status: data.status,
          progress: data.progress,
          currentStep: data.current_step,
          result: data.result
        })
        
        if (data.status === 'running') {
          setTimeout(checkStatus, 2000) // 每2秒查询一次
        }
      })
  }
  checkStatus()
}
```

### 状态流转
```
starting → running → completed/failed
   ↓          ↓           ↓
 0%      0-99%        100%
```


## 故障排查

### 问题1: 状态面板不出现
**原因**: 请求失败或响应错误
**解决**: 查看Console错误信息

### 问题2: 进度不更新
**原因**: 轮询失败或后端未返回进度
**解决**: 检查Network请求状态

### 问题3: 结果不显示
**原因**: 后端未返回result字段
**解决**: 等待任务完成或查看后端日志
