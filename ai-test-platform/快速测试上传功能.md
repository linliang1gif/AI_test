# 快速测试上传功能

## 🚀 快速开始

### 步骤1: 启动后端服务器

打开终端,运行:

```bash
cd ai测试/ai-test-platform
py backend_api_server.py
```

等待看到:
```
✅ 服务器启动成功!
📍 访问地址: http://localhost:8000
```

### 步骤2: 测试上传功能

#### 方法A: 使用前端界面(推荐)

1. 打开新终端,启动前端:
```bash
cd ai测试/ai-test-platform/frontend
npm run dev
```

2. 浏览器访问: http://localhost:5173

3. 点击左侧菜单"API Explorer"

4. 点击"上传Swagger文档"按钮

5. 选择文件: `test-swagger-example.json`

6. 查看结果:
   - ✅ 成功: 显示"成功解析 X 个API接口"
   - ❌ 失败: 显示具体错误信息

#### 方法B: 使用测试脚本

```bash
cd ai测试/ai-test-platform
py test_upload_fix.py
```

查看输出,所有测试应该显示"✅ JSON解析成功"

#### 方法C: 使用curl命令

```bash
curl -X POST http://localhost:8000/api/swagger/upload \
  -F "file=@test-swagger-example.json"
```

应该返回:
```json
{
  "success": true,
  "message": "成功解析 11 个API",
  "count": 11
}
```

## 🔍 问题排查

### 问题1: "上传失败: Failed to execute 'json' on 'Response'"

**原因**: 后端返回了非JSON格式的响应

**解决**:
1. 检查后端服务器是否正常运行
2. 查看后端控制台的错误日志
3. 确认修复已应用(检查`backend_api_server.py`第792行)

### 问题2: "Network Error" 或 "Failed to fetch"

**原因**: 前端无法连接到后端

**解决**:
1. 确认后端运行在8000端口: `netstat -ano | findstr :8000`
2. 检查前端代理配置: `frontend/vite.config.js`
3. 检查CORS配置

### 问题3: 上传成功但API列表为空

**原因**: 数据没有正确保存到内存数据库

**解决**:
1. 刷新页面重新加载API列表
2. 检查后端日志确认解析成功
3. 手动调用: `GET http://localhost:8000/api/apis`
