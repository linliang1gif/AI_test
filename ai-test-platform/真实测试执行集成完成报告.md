### 2. 支持的测试类型

#### 类型1: API测试 (source='api_generated')
```python
# 自动识别API信息
# 格式: "GET /api/users - 正常请求"
method, url = parse_api_info(test_case)

# 发送真实HTTP请求
response = requests.get(url, headers=headers, timeout=10)

# 验证响应
if response.status_code in [200, 201]:
    return {"status": "passed", ...}
```

**特点**:
- 真实HTTP请求
- 支持GET/POST/PUT/DELETE/PATCH
- 自动验证状态码
- 记录响应时间
- 错误处理(超时、连接失败)

#### 类型2: 自动化脚本测试 (有script_path)
```python
# 使用pytest执行脚本
result = await run_pytest(script_file)

# 或使用简单Python执行
result = await simple_python_exec(script_file)
```

**特点**:
- pytest集成
- JSON报告解析
- 降级到简单执行
- 测试结果统计

#### 类型3: 智能测试 (source='ai_generated')
```python
# 分析测试用例内容
if 'api' in title or '接口' in title:
    # 尝试作为API测试执行
    return await execute_api_test(test_case)
else:
    # 模拟执行
    return simulated_result
```

**特点**:
- 智能识别测试类型
- 自动选择执行方式
- 灵活适配

#### 类型4: 手动测试 (source='manual')
```python
return {
    "status": "pending",
    "message": "需要手动执行"
}
```

**特点**:
- 标记为待手动执行
- 不阻塞自动化流程

## 🔧 集成方式

### 后端集成

**修改**: `backend_api_server.py` 中的 `_execute_test_run` 方法

```python
async def _execute_test_run(self, task_id, run_id, test_cases, resume=False):
    # 导入真实测试执行器
    try:
        from executor.real_test_executor import get_test_executor
        executor = get_test_executor()
        use_real_executor = True
    except ImportError:
        use_real_executor = False
    
    # 执行每个测试用例
    for test_case in test_cases:
        if use_real_executor:
            # 使用真实执行器
            result = await executor.execute_test_case(test_case)
            test_passed = result["status"] == "passed"
        else:
            # 降级到模拟执行
            test_passed = random.random() < 0.8
```

**优点**:
- 自动降级机制
- 不影响现有功能
- 渐进式集成

## 📝 使用说明

### 1. 准备测试用例

**方式1: 从API Explorer生成**
1. 导入Swagger文档
2. 选择API生成测试用例
3. 测试用例自动标记为`source='api_generated'`

**方式2: AI生成**
1. 上传需求文档
2. AI生成测试用例
3. 测试用例标记为`source='ai_generated'`

**方式3: 关联自动化脚本**
1. 在Automation模块生成脚本
2. 在测试用例中添加`script_path`字段
3. 执行时自动调用脚本

## 🐛 故障排查

### 问题1: 执行器导入失败
```
⚠️ 真实测试执行器不可用,使用模拟模式
```

**解决**:
1. 检查文件路径: `executor/real_test_executor.py`
2. 检查Python路径
3. 重启后端服务器

### 问题2: API测试失败
```
❌ API连接失败 - 无法连接到目标服务器
```

**解决**:
1. 检查base_url配置
2. 确认目标服务器运行中
3. 检查网络连接
4. 查看防火墙设置
