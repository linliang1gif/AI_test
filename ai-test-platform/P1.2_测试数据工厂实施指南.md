```python
# 从模板生成

```

### 2. basic_generator.py ✅

**支持的数据类型**:
- string - 字符串(支持多种字符集)
- number/integer - 整数
- float - 浮点数
- boolean - 布尔值
- date - 日期
- datetime - 日期时间
- email - 邮箱
- phone - 手机号
- url - URL
- uuid - UUID

**特殊功能**:
- 边界值生成
- 非法值生成
- 自定义格式

**使用示例**:
```python
from test_data.generators import BasicDataGenerator

gen = BasicDataGenerator()

# 基础生成
string = gen.generate_string(length=10, charset='alphanumeric')
number = gen.generate_number(min_value=1, max_value=100)
email = gen.generate_email(domain='test.com')
phone = gen.generate_phone(country_code='86')

# 边界值
boundaries = gen.generate_boundary_values('integer', 0, 100)
# 返回: [-1, 0, 1, 99, 100, 101]

# 非法值
invalid = gen.generate_invalid_values('email')
# 返回: [None, '', 'invalid', 'invalid@', ...]
```
