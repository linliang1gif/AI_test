## 快速启动步骤

### 方式1: 使用一键启动脚本（推荐）

**Windows**:
```bash
cd ai测试/ai-test-platform
一键启动.bat
```

这将自动启动后端和前端服务。

### 方式2: 手动启动

**步骤1: 启动后端**（终端1）
```bash
cd ai测试/ai-test-platform
py backend_api_server.py
```

等待看到:
```
INFO:     Uvicorn running on http://127.0.0.1:8081
```

**步骤2: 启动前端**（终端2）
```bash
cd ai测试/ai-test-platform/frontend
npm run dev
```

等待看到:
```
  ➜  Local:   http://localhost:3000/
```

## 常见问题

### Q1: 前端无法连接后端
**解决**: 
- 确认后端已启动（http://127.0.0.1:8081）
- 检查防火墙设置
- 查看浏览器控制台错误信息

### Q2: AI生成失败
**解决**:
- 检查DeepSeek API Key是否正确
- 查看后端终端的错误信息
- 尝试切换到Mock模式（修改`.env`中`DEFAULT_AI_PROVIDER=mock`）

### Q3: 生成的测试用例为0
**解决**:
- 这个问题已修复！
- 如果仍然出现，请运行测试脚本验证:
  ```bash
  py test_ai_generation_fix.py
  ```

### Q4: 前端页面空白
**解决**:
- 确认Node.js已安装
- 运行 `npm install` 安装依赖
- 检查前端终端的错误信息
