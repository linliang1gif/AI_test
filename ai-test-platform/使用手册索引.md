## 🎯 按场景分类

### 场景1: 第一次使用
**阅读顺序**:
1. `README.md` - 了解项目
2. `快速入门_AI控制台.md` - 快速上手
3. 运行 `python quick_test.py` - 验证系统
4. 打开 http://localhost:5173/ai-test-console - 开始使用

### 场景2: 日常开发
**常用操作**:
1. 打开 AI测试控制台
2. 输入需求和代码变更
3. 执行测试查看结果
4. 根据AI建议优化代码

**参考文档**: `AI测试控制台使用说明.md`

### 场景3: 新功能测试
**操作流程**:
1. 打开 `/projects` 页面
2. 上传需求文档和Swagger
3. AI生成测试用例和脚本
4. 执行测试生成报告

**参考文档**: `完整流程使用说明.md`

### 场景4: 问题排查
**排查步骤**:
1. 运行 `python check_system.py` - 检查服务
2. 查看后端日志 - Terminal输出
3. 使用Trace ID查询 - `/api/pipeline/trace/{id}`
4. 查看API文档 - http://localhost:8000/docs

**参考文档**: `AI控制台界面说明.md`（故障排查部分）

### 场景5: 团队演示
**准备工作**:
1. 阅读 `使用演示脚本.md` - 演示话术
2. 运行 `python demo_ai_console.py` - 预演
3. 打开 `frontend/test_ai_console.html` - 快速入口
4. 准备演示数据

**演示时长**: 5-10分钟
