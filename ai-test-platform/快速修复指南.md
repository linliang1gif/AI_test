## 💡 解决方案(3选1)

### 方案1: 使用 Mock 模式 (最快 - 1分钟)

**适用场景**: 快速测试系统功能,不需要真实 AI

**步骤**:

1. 修改 `.env` 文件:
```env
DEFAULT_AI_PROVIDER=mock
DEFAULT_AI_MODEL=mock-model
```

2. 重启后端:
```bash
# 停止旧服务 (Ctrl+C)
# 启动新服务
py backend_api_server.py
```

3. 测试:
```bash
py quick_test.py
```

**优点**:
- ✅ 立即可用,无需配置
- ✅ 完全免费
- ✅ 响应速度快

**缺点**:
- ❌ 返回固定的 Mock 数据
- ❌ 无法测试真实 AI 能力

---

### 方案2: 使用 Ollama 本地模型 (推荐 - 30分钟)

**适用场景**: 需要真实 AI,但不想花钱

**步骤**:

1. **安装 Ollama**:
   - 访问: https://ollama.com/download
   - 下载 Windows 版本
   - 安装并启动

2. **下载模型**:
```bash
# 快速模型 (1.5GB)
ollama pull qwen2.5:1.5b

# 或者更好的模型 (4.7GB)
ollama pull qwen2.5:7b
```

3. **修改 `.env` 文件**:
```env
DEFAULT_AI_PROVIDER=ollama
DEFAULT_AI_MODEL=qwen2.5:1.5b
OLLAMA_BASE_URL=http://localhost:11434
```

4. **重启后端**:
```bash
py backend_api_server.py
```

5. **测试**:
```bash
py quick_test.py
```

**优点**:
- ✅ 完全免费
- ✅ 数据隐私(本地运行)
- ✅ 无网络依赖
- ✅ 真实 AI 能力

**缺点**:
- ❌ 需要下载模型(1-5GB)
- ❌ 需要较好的电脑配置
- ❌ 首次响应较慢(5-10秒)

---

### 方案3: 申请新的 API Key (最佳 - 1小时)

**适用场景**: 生产环境,需要最好的 AI 质量

#### 选项A: DeepSeek (推荐)

**价格**: 0.001元/1K tokens (非常便宜)

**步骤**:
1. 访问: https://platform.deepseek.com
2. 注册账号
3. 充值 10-50 元(可用很久)
4. 创建 API Key
5. 修改 `.env`:
```env
DEFAULT_AI_PROVIDER=deepseek
DEFAULT_AI_MODEL=deepseek-chat
DEEPSEEK_API_KEY=sk-你的新key
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
```

#### 选项B: OpenAI

**价格**: $0.002/1K tokens (较贵)

**步骤**:
1. 访问: https://platform.openai.com
2. 注册账号(需要国外手机号)
3. 充值 $5-20
4. 创建 API Key
5. 修改 `.env`:
```env
DEFAULT_AI_PROVIDER=openai
DEFAULT_AI_MODEL=gpt-3.5-turbo
OPENAI_API_KEY=sk-你的新key
OPENAI_BASE_URL=https://api.openai.com/v1
```

## ❓ 常见问题

### Q1: Mock 模式够用吗?
A: 如果只是测试系统功能,Mock 模式完全够用。但如果需要真实的 AI 分析能力,建议使用 Ollama 或云端 API。

### Q2: Ollama 需要什么配置?
A: 
- CPU: 4核以上
- 内存: 8GB 以上
- 硬盘: 10GB 空闲空间
- 系统: Windows 10/11

### Q3: DeepSeek 和 OpenAI 哪个好?
A: 
- **DeepSeek**: 便宜,中文好,速度快 (推荐)
- **OpenAI**: 质量最好,但贵,需要科学上网

### Q4: 如何切换 AI 提供商?
A: 只需修改 `.env` 文件中的 `DEFAULT_AI_PROVIDER` 和 `DEFAULT_AI_MODEL`,然后重启服务即可。
