# AI 测试决策系统 - 三阶段流程使用指南

## 🎯 系统概述

AI 测试决策系统是一个完整的自动化测试决策和执行平台，通过三个核心模块协同工作：

```
需求/代码变更
      ↓
🤖 Test Agent (AI决策)
      ↓
📋 Strategy Engine (策略生成)
      ↓
⚡ Orchestrator (执行调度)
      ↓
📊 测试结果
```

---

## 📦 三大核心模块

### 1. Test Agent (AI 测试决策中心)
**职责**: 分析需求和代码变更，决定是否需要测试

**输入**:
- 需求文档
- Git Diff

**输出**:
- action: run_tests / skip
- priority: P0 / P1 / P2
- modules: 影响的模块列表
- risk_level: 高 / 中 / 低
- confidence: 0.0 - 1.0

**API**: `POST /api/agent/analyze`

---

### 2. Strategy Engine (测试策略引擎)
**职责**: 根据 Agent 决策生成结构化测试策略

**输入**: Agent 决策结果

**输出**:
- strategy: 每个模块的测试策略
  - module: {name, impact}
  - test_types: [api, ui, integration]
  - case_count: 预估用例数
  - execution_hint: {parallel, timeout}
- summary: 统计摘要

**API**: `POST /api/strategy/generate`

---

### 3. Orchestrator (测试执行调度器)
**职责**: 根据策略自动调度并执行测试

**输入**: Strategy 策略结果

**输出**:
- results: 每个模块的执行结果
  - module: 模块名
  - status: passed / failed
  - duration: 执行时长
  - details: 详细日志
- summary: 执行摘要
  - total / passed / failed
  - pass_rate / duration

**API**: `POST /api/orchestrator/run`

## 🚀 快速开始

### 方式1: Python 代码调用

```python
from agent.test_agent_service import get_test_agent_service
from strategy.strategy_service import get_strategy_service
from orchestrator.orchestrator_service import get_orchestrator_service

# 阶段1: Agent 决策
agent = get_test_agent_service()
agent_result = agent.analyze(requirement, git_diff)

# 阶段2: Strategy 生成
strategy = get_strategy_service()
strategy_result = strategy.generate_strategy(agent_result)

# 阶段3: Orchestrator 执行
orchestrator = get_orchestrator_service()
execution_result = orchestrator.run(strategy_result)

print(f"通过率: {execution_result['summary']['pass_rate']}%")
```

### 方式2: HTTP API 调用

```bash
# 1. Agent 分析
curl -X POST http://localhost:8000/api/agent/analyze \
  -H "Content-Type: application/json" \
  -d '{"requirement": "...", "git_diff": "..."}'

# 2. Strategy 生成
curl -X POST http://localhost:8000/api/strategy/generate \
  -H "Content-Type: application/json" \
  -d '{"agent_decision": {...}}'

# 3. Orchestrator 执行
curl -X POST http://localhost:8000/api/orchestrator/run \
  -H "Content-Type: application/json" \
  -d '{"strategy": {...}}'
```
