## 🎯 使用方法

### 访问系统
1. **打开浏览器**: http://localhost:3000
2. **进入AI Insights页面**
3. **点击 "AI Provider Settings" 按钮**

### 选择AI提供商
1. **查看提供商卡片**
   - 绿色图标 = 可用
   - 红色图标 = 不可用
   - 蓝色标签 = 本地服务
   - 紫色标签 = 云端服务

2. **点击提供商卡片进行切换**
   - 当前选择的提供商会有蓝色边框
   - 系统会自动保存选择

3. **查看模型信息**
   - 每个提供商显示可用模型数量
   - 显示默认模型名称

### 智能功能
- **自动模型选择**: 系统根据任务类型自动选择最适合的模型
- **回退机制**: 大模型超时时自动切换到轻量级模型
- **实时状态**: 提供商状态实时更新

## 🔄 工作流程

### 用户操作流程
```
1. 用户访问 AI Insights 页面
2. 点击 "AI Provider Settings"
3. 查看可用提供商列表
4. 点击选择提供商
5. 系统切换到选定提供商
6. 开始使用AI功能
```

### 系统处理流程
```
1. 前端发送 GET /api/ai/providers/list
2. 后端检查 Ollama 服务状态
3. 返回提供商列表和状态
4. 前端显示提供商卡片
5. 用户点击选择提供商
6. 前端发送 POST /api/ai/providers/select
7. 后端更新当前提供商
8. 返回成功确认
```

## 🛠️ 故障排除

### 常见问题

#### 1. 提供商显示不可用
**解决方案**:
- 检查 Ollama 服务: `ollama serve`
- 检查模型是否下载: `ollama list`
- 重启服务: 停止并重新启动 API 服务器

#### 2. 前端无法连接后端
**解决方案**:
- 确认后端服务运行在 8000 端口
- 检查 CORS 配置
- 查看浏览器控制台错误信息

#### 3. 模型选择不生效
**解决方案**:
- 检查提供商选择是否成功
- 验证模型是否可用
- 查看后端日志

### 调试命令
```bash
# 检查服务状态
curl http://localhost:8000/api/ai/providers/list

# 测试提供商选择
curl -X POST http://localhost:8000/api/ai/providers/select \
  -H "Content-Type: application/json" \
  -d '{"provider_id": "ollama"}'

# 检查 Ollama 状态
ollama list
ollama ps
```
