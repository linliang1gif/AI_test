# AI测试平台 - 标准演示流程

## 🎯 演示目标

展示AI测试平台的完整测试执行流程,从测试用例创建到报告生成。

## 🚀 快速开始

### 一键运行

```bash
cd demo
python run_demo.py
```

就这么简单!无需任何配置或手动干预。

## 📋 演示内容

### 测试场景
- **目标系统**: 用户管理API
- **API地址**: https://jsonplaceholder.typicode.com
- **测试用例**: 4个

### 测试用例列表

1. **TC_001**: 获取用户列表
   - 方法: GET /users
   - 预期: 200 OK

2. **TC_002**: 获取单个用户
   - 方法: GET /users/1
   - 预期: 200 OK

3. **TC_003**: 创建用户
   - 方法: POST /users
   - 预期: 201 Created

4. **TC_004**: 获取不存在的用户
   - 方法: GET /users/999
   - 预期: 404 Not Found

## 📊 执行流程

```
步骤1: 创建测试用例
    ↓
步骤2: 执行测试
    ↓
步骤3: 生成报告
    ↓
步骤4: 生成HTML报告
```

## 🔍 故障排查

### 问题1: 网络连接失败

**错误**: `requests.exceptions.ConnectionError`

**解决**: 检查网络连接,确保可以访问 https://jsonplaceholder.typicode.com

### 问题2: 模块导入失败

**错误**: `ModuleNotFoundError`

**解决**: 确保在项目根目录运行,或安装依赖:
```bash
pip install requests
```

### 问题3: 权限错误

**错误**: `PermissionError`

**解决**: 确保有写入 `output/` 目录的权限

## 📝 自定义演示

### 修改测试用例

编辑 `run_demo.py` 中的 `create_test_cases()` 函数:

```python
def create_test_cases():
    test_cases = [
        {
            'id': 'TC_001',
            'name': '你的测试用例',
            'type': 'api',
            'api': {
                'method': 'GET',
                'url': 'https://your-api.com/endpoint',
                'expected_status': 200
            }
        }
    ]
    return test_cases
```

### 修改API地址

更改测试用例中的 `url` 字段即可。

### 自定义报告样式

编辑 `generate_html_report()` 函数中的HTML模板。
